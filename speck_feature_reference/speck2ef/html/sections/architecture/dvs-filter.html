3.4. DVS Event Filter

The DVS Filter Block is included in the DVS pre-processing layer of Speck2e in order to filter events depending on neighboring pixel activity.

In general, an event at position (x,y) is forwarded by the filter when at least one pixel in the vicinity of (x,y) has spiked in a defined time window before the (x,y) event.

3.4.1. Filter Operation

The filter can be enabled by setting register bit HPFE to ‘1’.

Whenever a pixel event arrives at the filter, the filter stores in its SRAM the time stamp of the event at that location.

When a new pixel event arrives at the filter at location (x0,y0), the filter checks the area defined by register bits FKSX[2:0] and FKSY[2:0], i.e. (x0±FKSX,y0±FKSY) to see if any event was recorded in that area in a number of clock cycles defined by register bits FDEL[15:0].

The time stamps are recorded using a 16-bit loop counter. Each count is triggered by the internal slow clock (see Internal Slow Clock and Slow Clock Configuration). The input clock for the filter is activated by register bit FCKE.

3.4.2. Monitor bus

The filter has a monitor bus output, which forwards all events produced in the filter before the final counter comparison, i.e., for each input event to the filter, and a filter size setting FKSX=’010’, FKSY=’001’, 5*3=15 messages will be forwarded by the filter to the monitor bus, irrespectively if any event would be forwarded at the filter output.

Note

If the input event is near the edge of the pixel field, the filter size will be clipped accordingly. Therefore, less locations will be evaluated by the filter, and less messages will be forwarded on the monitor bus.

The monitor bus can be activated via register bit FMOE, and a 4-bit tag defined by FMDST[3:0] is prepended to the monitor message as tag/address.

Warning

The order of the monitor messages (#1, #2, #3) is not guaranteed due to the asynchronous nature of the internal logic. Necessary precautions should be therefore taken when analyzing the output message sequence.

3.4.2.1.1. Message #1

Returns the X/Y/Polarity information for the internally generated Counter update in memory.

For a SRAM Read operation via Input Interface command, this message will forward the SRAM read address (Y[6:0],X[6:0]) (the Polarity bit is a don’t care in this case).

3.4.2.1.2. Message #2

Returns the current Counter value of the original event received from the Event Pre-Processing Layer.

For a SRAM Read operation, this message can be disregarded as a don’t care.

3.4.2.1.3. Message #3

Returns the previous Counter value at the location X/Y (from Message #1), i.e., the counter value stored in the SRAM.

For a SRAM Read operation, this message will contain the data read from the given location (Y[6:0],X[6:0]).

3.4.3. Configuration

3.4.3.1. Filter window size

The filter window size can be configured using registers FKSX[2:0] and FKSY[2:0], respectively in the X and Y directions.

Note

The filter window goes from x0-FKSX to x0+FKSX (and same for Y). I.e., the filter size can go from 1x1 pixel to 15x15 pixels.

3.4.3.2. Filter Delta/Threshold

The filter time delta can be configured with register bits FDEL[15:0].

This value is used to compare the current counter value with the value of the pixels neighboring the current spiking pixel. If any of the neighboring pixels has a value difference withing the delta value, the filter emits the current spike. Otherwise, the current spike is blocked.

3.4.3.3. Low-Pass mode

Note

Low-Pass filter mode is available only in Speck2f.

In this mode, the filter works as a low-pass filter. This mode can be used to filter out 50/60 Hz light flickering noise produced by some lights such as fluorescent or LED lights that output a square wave with the frequency of the mains power supply.

The mode can be enabled by setting register bit FLPF.

3.4.4. SRAM Read/Write Operations

Similar to the other SRAMS, the DVS Filter SRAM can be read/written directly using the internal BIST interface. The memory can be written either using the external SPI Slave interface or the JTAG interface.

Please refer to section DVS Filter Memory for the Filter SRAM memory mapping.
