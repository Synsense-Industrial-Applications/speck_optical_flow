3.3. Event Pre-Processing Layer

The event pre-processing layer receives as input the events coming from the internal DVS, or from an external source through the Input Serial Interface (see ISI Addressing).

Depending on its register configuration, the event pre-processing Layer can process the input messages to provide the following operations:

  • Select messages and forward on only / off only / all messages to one or two desired destinations. The polarity of the events can also be merged (all events become on events). Register configuration.

  • Sum pooling 1:1, 1:2, 1:4. X Configuration, Y Configuration.

  • ROI selection. X range [start:end], Y range [start:end].

  • Mirroring in both X/X.

  • Rotate in 90 degree steps. This can be achieved by X/Y mirroring + image transposition.

  • Two selectable destination layers. Destination 1 enable and address, destination 2 enable and address.

3.3.1. Event Filter

An event filter is included in the DVS Event Pre-processing Layer. The filter can be enabled by setting register bit HPFE to ‘1’. The filter has its own set of configuration registers (see Filter Registers).

3.3.2. Event Pre-Processing Pipeline

The general processing pipeline for the pre-processing layer is as follows:
