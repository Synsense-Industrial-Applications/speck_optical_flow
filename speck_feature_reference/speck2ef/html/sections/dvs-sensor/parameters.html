5.2. Internal DVS Sensor Parameters

In order for the internal DVS sensor to operate, a number of settings have to be configured, mainly through the DVS Register block and dedicated pixel field power supplies.

In this section, we provide a description of all the settings and their base values.

5.2.1. Sensor Main Bias Settings

5.2.1.1. Main Bias Enable Settings

Only one of the main_bias1, main_bias2 or main_bias3 should be enabled with their respective enable signals (sensor_en_bias1, sensor_en_bias2 or sensor_en_bias3).

5.2.1.2. Start-Up Settings

In order to activate the start-up, both sensor_en_startupref and one of the sensor_en_startup1 or sensor_en_startup2 should be enabled.

5.2.2. Sensor Register Settings

5.2.2.1. Current settings:

  • SIO1[5:0] (sensor_iout1): sets the reference current for parameter 0. This sets the buffer bias current placed after the logamp.

  • SIO2[5:0] (sensor_iout2); sets the reference current for parameter 1. This sets the logamp bias current.

  • SIO3[5:0] (sensor_iout3): sets the reference current for parameters 2, 3, 4 and 5. This sets the differencing amplifier and comparator currents and sets the reset voltage level.

  • SIO4[5:0] (sensor_iout4): sets the reference current for parameter 6 and 7. This sets the reset/ignore pulse width currents.

For all sensor_iout register signals, the general rule applies:

  • 0: lowest current

  • 63: highest current

For parameter 0 and parameter 1, there is an option to set the currents with finer steps via SP1[3:0] (sensor_p0) and SP1[3:0] (sensor_p1), respectively. SP1[3:0] (sensor_p0) and SP1[3:0] (sensor_p1) are binary with the following rule:

  • 0: highest current

  • 14: lowest current

Note

For parameter 1, the arrangement between consecutive SP1[3:0] (sensor_p1) and SIO2[5:0] (sensor_iout2) is such that SP1[3:0] (sensor_p1) introduces 16 finer current steps between consecutive SIO2[5:0] (sensor_iout2) configurations. Example: For a given SIO2[5:0] (sensor_iout2), if SP1[3:0] (sensor_p1) is 0011, the set current is SIO2[5:0] (sensor_iout2) x12/16.

Note

For parameter 0, the arrangement between consecutive SP1[3:0] (sensor_p0) and SIO1[5:0] (sensor_iout1) is such that SP1[3:0] (sensor_p0) introduces 64 finer current steps between SIO1[5:0] (sensor_iout1) configurations. Example: For a given SIO1[5:0] (sensor_iout1), if SP1[3:0] (sensor_p0) is 0011, the set current is SIO1[5:0] (sensor_iout1) x12/64. Due to SP1[3:0] (sensor_p0) being 4-bit signal, and the division is being 64, some current values are not reachable.

5.2.2.2. Pixel threshold settings

  • SP3[4:0] (sensor_p3): sets ON threshold voltage. Note: this voltage should be lower than the pixel RESET voltage. If the current setting is lower, the resulting ON threshold voltage increases.

  • SP4[4:0] (sensor_p4): sets the pixel RESET voltage. If the current setting is lower, the resulting RESET voltage increases.

  • SP5[4:0] (sensor_p5): sets OFF threshold voltage. Note: this voltage should be higher than the pixel RESET voltage. If the current setting is lower, the resulting OFF threshold voltage increases.

  • SP6[3:0] (sensor_p6): sets the IGNORE time of the events after receiving an event from a pixel. This setting is similar to sensor_p7, i.e., if the current is lower, the IGNORE time is longer.

  • SP7[3:0] (sensor_p7): sets the pixel RESET time. If the current is lower, the reset pulse width is longer–meaning that it keeps the RESET longer. This might help to lower the pixel event rate if too high.

5.2.2.3. Setting configurations

Each parameter sensor_p3-7 internally selects a current multiplication factor. This multiplication is binary with the following rule:

  • 0: highest current

  • 31: lowest current

5.2.2.4. How to adjust the settings:

Normally if you apply the same config parameter for p3, p4 and p5, this guarantees that:

  • The ON voltage is lower than the RESET voltage

  • The OFF voltage is higher than the RESET voltage

If you would like to set the ON voltage lower than that value, and the OFF voltage higher than that value:

  • Set ON voltage to a higher current setting than RESET voltage

  • Set OFF voltage to a lower current setting than RESET voltage

Tip

If sensor_p4 (RESET voltage) is set to ‘11001’ (6*I), you normally need to set the other parameters to ‘11001’ However, if you would like to increase the OFF voltage, and decrease the ON voltage, you can set:

  • sensor_p3 (ON voltage): ‘00000’ (32*I)

  • sensor_p5 (OFF voltage): ‘11110’ (1*I)

5.2.3. Set of initial working settings (latest)

5.2.3.1. Power supplies

  • vdda_pixel=1.2V

  • vddd_pixel=1.2V

  • vdd_logic=1.2V

5.2.3.2. Current settings (registers)

  • DVS8[7:0] = 1110_1110 (sensor_p1 and sensor_p0)

  • DVS9[4:0] = 1_1001 (sensor_p3)

  • DVS10[7:5] = 101 (sensor_en_startup1, sensor_en_startup2, and sensor_en_startupref)

  • DVS10[4:0] = 1_1001 (sensor_p4)

  • DVS11[7:5] = 100 (sensor_en_bias1, sensor_en_bias2, and sensor_en_bias3)

  • DVS11[4:0] = 1_1001 (sensor_p5)

  • DVS12[7:0] = 1110_1110 (sensor_p7 and sensor_p6)

  • DVS13[5:0] = 00_1110 (sensor_iout1)

  • DVS14[5:0] = 10_0000 (sensor_iout2)

  • DVS15[5:0] = 00_1010 (sensor_iout3)

  • DVS16[5:0] = 11_1111 (sensor_iout4)

5.2.4. VBIAS and VREF Pad Explanation

VBIAS pad in the pinout diagram is used to bias the gate of the one of the pixel types in SYNS91104 (Speck2et) with an analog voltage. It is not connected to any internal connections in SYNS91103/SYNS91105 (Speck2e/Speck2f). You can left it open.

VREF pad in the pinout diagram is used to monitor the generated reference voltage in the main bias circuit. It outputs an analog voltage. To monitor it, you can connect the pad to a capacitance and use a multimeter or a similar device.
