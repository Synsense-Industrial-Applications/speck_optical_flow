10.2. SPI Slave

The SPI slave interface provides a way to access Register and SRAM memories in Speck2e. In this page, the protocol and memory addressing schemes are described.

10.2.1. SPI Modes

The following SPI modes are supported:

  • Mode 0: CPOL = 0, CPHA = 0

  • Mode 3: CPOL = 1, CPHA = 1

SPI clock could run up to 1/16 of main clock frequency, max. 6.25 MHz.

In single mode (SM) the address can only be one of the first 2^16 addresses.

In long burst mode (LBM) the starting address is specified in register BADDR (24 bit) and burst length in BLEN (24 bit).

  • Single write

  • Single read

  • Burst write

  • Burst read

10.2.4.3. SRAMs

The internal SRAMs can be accessed using SPI through their BIST interfaces.

The addressing of the SRAMs follows the descriptions in BIST Address mapping. For each SRAM, the BIST address for the first SRAM word is always 0x00000. When accessing the specific SRAM via SPI, the starting address listed in the following table matches address 0x00000 of that SRAM.

Note

For compatibility reasons, all SRAMs have the same available addressing size. Nonetheless, some SRAMs utilize only part of this addressing space. It is responsibility of the user to not write unavailable address locations. For example, Leak SRAMs are 1ki elements in size, so for Leak SRAM of layer 3, address 0x36_03FF should not be exceeded.

10.2.4.3.1. Example

We want to write Neuron 137 of Layer 2:

Neuron SRAMs have 16-bit words, so we need to do two writes of 8 bits.

The address of the LSB part of the Neuron data is then:

  • Starting SRAM addressing: 0x14_0000

  • Neuron in hex: hex(137) = 0x89

  • 2x locations per neuron -> starting relative location = 0x89 * 2 = 0x112

Address of 8 LSB = 0x14_0112 Address of 8 MSB = 0x14_0113
