8.3. Direct Memory Access Mode (BIST)

In Speck2e, all internal SRAMs can be directly read/written only through the SPI and JTAG interfaces. Both these interfaces communicate to the memory via the physical BIST SRAM interfaces.

8.3.1. BIST Address mapping

Since the BIST interface in Speck2e has an 8-bit bus width, while some internal SRAMs require 16-bit data elements, the BIST address scheme for the various SRAMs is defined to enable writing/reading a 16-bit data element in two 8-bit write/read operations.

8.3.1.1. Kernel Memories

In all kernel memories (8-bit data elements), the internal addressing is equivalent to the BIST addressing.

8.3.1.2. Leak/Neuron/Filter Memories

In all Leak/Neuron/Filter memories, each internal memory element can be accessed by 2 BIST R/W operations.
