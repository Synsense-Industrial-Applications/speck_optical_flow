8.1. Memory configuration

SRAM memory blocks are distributed across Speck2e in order to store Kernel/Leak/Neuron information of convolutional layers as required for proper operation of the neuromorphic processor.

In addition, an SRAM block is included in the DVS Event Filter to store Counter information.

8.1.1. Memory Capacity and Internal Addressing

8.1.2. Memory Layout

All memory access is done by layer. The internal address format is dynamic and depends on the feature sizes and kernel dimensions of the layer being accessed.

All binary expressions have the most significant bit on the left side.

8.1.2.1. Neuron Memory

There are 16 bits available for adressing neuron memory per layer. The address format is

zero fill

neuron y

neuron x

feature

The bit field size is computed as

\[\begin{split}[\text{neuron y}] &= \lceil \log_2\left(f_y\right) \rceil \\ [\text{neuron x}] &= \lceil \log_2\left(f_x\right) \rceil \\ [\text{feature}] &= \lceil \log_2\left(f\right) \rceil\end{split}\]

8.1.2.2. Example

Let \(f_x=16,f_y=16,f=128\)

The neuron address of the neuron in feature map 63 with x address 3 and y address 11 is then

zero fill (1 bit)

neuron y (4 bits)

neuron x (4 bits)

feature (7 bits)

0

1011

0011

0111111

8.1.2.3. Kernel Memory

There are maximally 16 bits available for addressing neuron memory per layer.

The address format is:

zero fill

kernel entry

output feature

input feature

Note

Kernel entries are not addressed by their x,y position. Instead they are numbered using row major order. The kernel entry address of a kernel element with position \((x,y)\) becomes \(k_yy+x\)

The bit field size is computed as

\[\begin{split}[\text{kernel entry}] &= \lceil \log_2\left(k_xk_y\right) \rceil \\ [\text{output feature}] &= \lceil \log_2\left(f\right) \rceil \\ [\text{input feature}] &= \lceil \log_2\left(c\right) \rceil\end{split}\]

8.1.2.4. Example

Let \(k_x=k_y=3,f=128,c=64\)

The address for kernel element 6 in the kernel applied to input feature 28 to generate output feature 71 is then

kernel entry (4 bits)

output feature (7 bits)

input feature (6 bits)

110

1000111

011100

8.1.2.5. Leak Memory

There are 10 bits available for addressing leak memory per layer.

The address format is:

feature

8.1.2.6. Example

If the layer has 5 output features (see CONV5:OFN), the leak memory contains 5 entries, simply going from address 0x000 to 0x005.

8.1.2.7. DVS Filter Memory

There are 14 bits available for addressing the DVS Filter memory.

The address format is:
