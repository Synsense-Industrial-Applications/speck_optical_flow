7.8.1. Detailed Signal Description

7.8.1.1. LxDSTy (layerx_dsty)

Location: ROUTER0 to ROUTER8

Layer x destination address for destination y, where:

x = 0..8 y = 1 or 2

The address is composed of 4 bits:

Address

Destination

0b0000:0b1000

Layer 0 to 8

0b1100

Readout layer

7.8.1.2. LxDyEN (lx_dsty_en)

Location: ROUTER10 to ROUTER11

Layer x destination enable bit for destination y, where:

x = 0..8 y = 1 or 2

7.8.1.3. LxPLy (lx_poolingy)

Location: ROUTER12 to ROUTER37

Layer x destination y pooling setting, where:

x = 0..8 y = 1 or 2

Pooling for X and Y dimensions. Possible values are {0,1,2,3} mapping to {1,2,4,8}.

7.8.1.4. LxFNOy (lx_fnum_offsety)

Location: ROUTER12 to ROUTER36

Layer x destination y feature number offset setting, where:

x = 0..8 y = 1 or 2

Destination y Feature Number Shift. Shift the feature number of features going to destination by N. It is important to configure this number correctly so that there is no overlap in feature space between inputs and outputs. When configuring take into account the feature space of each input for a layer and shift them so that they don’t overlap in the input of the destination layer.

7.8.1.5. LxMEN (lx_mon_en)

Location: ROUTER39 and ROUTER40

x = 0..8

Layer x monitor bus enable bit. ‘1’: monitoring enabled for layer x, ‘0’: monitoring disabled for layer x.

7.8.1.6. LxMTAG (lx_mon_tag)

Location: ROUTER40 to ROUTER44

x = 0..8

Layer x monitor bus tag address. The 4 bits of the LxMTAG register are appended as MSBs to the layer output spike data before it is sent to the monitor bus (see Monitor Bus Encoding).
