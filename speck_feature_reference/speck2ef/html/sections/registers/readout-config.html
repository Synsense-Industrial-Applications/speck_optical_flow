7.14.1. Detailed Signal Description

7.14.1.1. CBn[2:0] (clk_blkn)

See Timing Configurations.

7.14.1.2. RBn[2:0] (rst_blkn)

See Timing Configurations.

7.14.1.3. AVGSEL[3:0] (average_sel)

Readout Layer Average Selection. Used when INEN == ‘1’. See Output Neuron selection for more details.

7.14.1.4. OMSEL[1:0] (output_mode_sel)

Readout Layer Mode Selection. Used when INEN == ‘1’. See Data Output Modes for more details.

7.14.1.5. TH[15:0] (readout_threshold)

Readout neurons threshold value. Defaults to 0.

The moving average of the output neurons is compared to the threshold value to produce an output if the received number of spikes is greater than the threshold.

See Readout Layer (Post Processing) for further information on the readout layer.

7.14.1.6. CH1 (choose_1)

Disables readout low pass filtering.

Note

This register overrides CH1632 when set to ‘1’.

CH1

Configuration

0 (default)

time window = selected by CH1632

1

time window = 1 MOVING_AVERAGE_CLK period

7.14.1.7. CH1632 (choose_16_32)

Selects readout moving average length (16 or 32 clock periods).

Note

If CH1 is set, CH1632 is overridden and low pass filtering is disabled.

CH1632

Configuration

0 (default)

time window = 16* MOVING_AVERAGE_CLK period

1

time window = 32* MOVING_AVERAGE_CLK period

7.14.1.8. ROCS[1:0] (readout_conf_sel)

Readout configuration selection: addressing modes of the incoming spikes.

There are 4 different addressing modes that could be selected. The valid configurations are the following:

ROCS[1:0]

Configuration

00

2x*2y*4f

10

4x*4y*1f

01

2x*4y*2f

11

1x*1y*16f

Where x, y and f represent, respectively, the X, Y and Feature dimensions of the events arriving at the Readout Layer.

7.14.1.9. BYPREG (bypass_reg)

When enabled, the output Flip-Flop is bypassed, and the moving average values are directly pushed to the output bus data2 without a register in between.

In typical operation, BYPREG should be set to ‘0’.

7.14.1.10. OVRTH (override_threshold_max)

Override Output Layer Threshold compare. Sends interrupt at each slow clock cycle.

7.14.1.11. INEN (reg_input_enable)

Use register configurations or input serial interface settings for average_sel and output_mode_sel:

Setting

Description

‘0’

average_sel and output_mode_sel are set by providing a special command to the Input Serial Interface

‘1’

average_sel and output_mode_sel are set by register bits AVGSEL[3:0] and OMSEL[1:0]

7.14.1.12. REQDLY[7:0] (io_interface_req_delay)

This register element configures the delay of the request signal to the output serializer. This delay is implemented in order to ensure that the request signal arrives after the data is valid at the output serializer. For example, when using direct SRAM access through the BIST interface, the request signal to the output serializer comes directly from the read request to the SRAM. For this reason, a delay is introduced to respect the data ready timing of the SRAM.
