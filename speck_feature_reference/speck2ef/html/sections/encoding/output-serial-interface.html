9.6. Output Serial Interface Encoding

As described in the output-serial-interface section, the output interface receives data from both the Monitor bus (data1, channel #1) and the Output MUX (data2, channel #2).

9.6.1. Source 1 (Monitor bus)

The encoding of the Monitor bus can be found in section: Monitor Bus Encoding.

9.6.2. Source 2 (Readout Layer)

When Source 2 is selected to be sent to the output serial interface, output serializer outputs the state of the Readout Layer For the encoding in normal operation, see Data Output Modes.
