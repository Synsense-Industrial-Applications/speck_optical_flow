9.2. Input Serial Interface

The serial to parallel converter (S2P) is an interface that receives serial data from an external source such as a sensor, microcontroller of an FPGA and converts it to the parallel data as an appropriate data feed for the IC.

A symbol of the S2P block is shown in the following.

An example waveform for how we can communicate with S2P block is shown in the following. Please note the S2P_CREADY signal which is HIGH whenever the S2P block is ready to accept new data and stays HIGH until the first bit of the new data frame is received.

Note

The S2P_DATA signal is sampled at the clock rising edge.

Setup and hold times for the S2P_DATA signals are of 100 ps.
