9.3. Input Serial Interface Bus Encoding

The Input Serial Interface (ISI) of Speck2e extends the standalone chip functionality by enabling:

  • Direct injection of Events (spikes) from the outside.

  • Use of an external DVS (or equivalent) sensor instead of the internal DVS.

  • Sensor pixel configuration.

  • On the fly configuration of the Readout Layer modes.

The ISI receives 32-bit data frames (see input-serial-interface for the communication protocol). Their encoding is defined in order to optimize bandwith utilization.

Note

The SPI Slave interface is still active while using the ISI, and can be used in parallel to read/write SRAM or register memories.

9.3.1. Reset Signals

The ISI provides its own reset signals to the internal chip blocks.

If the user wants to set the internal reset signals via the ISI, the bit CGUIS must be set to ‘1’.

Note

If the internal reset signals are set via the registers, and no special ISI command has been issued yet, if the user sets CGUIS = ‘1’, all the internal resets immediately go to ‘0’. Normally, the user should set the ISI Reset Signals to the current register set value, then set CGUIS = ‘1’.

10001000000000000000000000000000   # PRst='1': release PRst
10001100000000000000000000000000   # SRst='1': release SRst
11011000000000000000000000000000   # PRst_DVS='1': release PRst_DVS (optional)
11011100000000000000000000000000   # SRst_DVS='1': release SRst_DVS (optional)
