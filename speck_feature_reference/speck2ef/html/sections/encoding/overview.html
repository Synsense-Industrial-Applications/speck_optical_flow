9.1. I/O Interfaces Overview

Speck2e is equipped with four distinct input interfaces:

  • SPI Slave interface

  • SPI Master interface

  • JTAG

  • Asynchronous Serial Interface

9.1.1. SPI Slave

The SPI Slave interface can be used to program the internal Register and SRAM memories.

9.1.2. SPI Master

The SPI Master interface must be connected to a standard SPI Flash external memory and can automatically download the Flash contents to the internal SRAMs and Registers.

9.1.3. JTAG Interface

The RGB Interface provides access to all internal features of the chip, including:

  • SRAM/Register memories

  • Asynchronous input events

  • Asynchronous output events

  • Internal scan chains

9.1.4. Asynchronous Input Serial Interface

The Asynchronous Input Serial Interface enables fast input of Asynchronous events as well as configuration settings for the internal DVS Sensor.

Section Input Serial Interface provides a description of the custom physical communication protocol of the interface.

In Section Input Serial Interface Bus Encoding the message encoding for the interface is provided.

9.1.5. Asynchronous Output Serial Interface

The Asynchronous Output Serial Interface enables readout of Asynchronous events from the internal monitor bus, well as readout layer status information.

Section Output Serial Interface provides a description of the custom physical communication protocol of the interface.

In Section Output Serial Interface Encoding the message encoding for the interface is provided.
