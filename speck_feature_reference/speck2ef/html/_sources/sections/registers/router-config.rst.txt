Detailed Signal Description
***************************

.. _rbits-LxDSTy:

LxDSTy (layerx_dsty)
----------------------

Location: :ref:`ROUTER0<reg-ROUTER0>` to :ref:`ROUTER8<reg-ROUTER8>`

Layer x destination address for destination y, where:

x = 0..8
y = 1 or 2

The address is composed of 4 bits:

+---------------+---------------+
| Address       | Destination   |
+---------------+---------------+
| 0b0000:0b1000 | Layer 0 to 8  |
+---------------+---------------+
| 0b1100        | Readout layer |
+---------------+---------------+

.. _rbits-LxDyEN:

LxDyEN (lx_dsty_en)
----------------------

Location: :ref:`ROUTER10<reg-ROUTER10>` to :ref:`ROUTER11<reg-ROUTER11>`

Layer x destination enable bit for destination y, where:

x = 0..8
y = 1 or 2

.. _rbits-LxPLy:

LxPLy (lx_poolingy)
----------------------

Location: :ref:`ROUTER12<reg-ROUTER12>` to :ref:`ROUTER37<reg-ROUTER37>`

Layer x destination y pooling setting, where:

x = 0..8
y = 1 or 2

Pooling for X and Y dimensions. Possible values are {0,1,2,3} mapping to {1,2,4,8}.

.. _rbits-LxFNOy:

LxFNOy (lx_fnum_offsety)
-------------------------

Location: :ref:`ROUTER12<reg-ROUTER12>` to :ref:`ROUTER36<reg-ROUTER36>`

Layer x destination y feature number offset setting, where:

x = 0..8
y = 1 or 2

Destination y Feature Number Shift. Shift the feature number of features going to destination by N.
It is important to configure this number correctly so that there is no overlap in feature space between inputs and outputs.
When configuring take into account the feature space of each input for a layer and shift them so that
they don't overlap in the input of the destination layer.

.. _rbits-LxMEN:

LxMEN (lx_mon_en)
------------------

Location: :ref:`ROUTER39<reg-ROUTER39>` and :ref:`ROUTER40<reg-ROUTER40>`

x = 0..8

Layer x monitor bus enable bit. '1': monitoring enabled for layer x, '0': monitoring disabled for layer x.


.. _rbits-LxMTAG:

LxMTAG (lx_mon_tag)
--------------------

Location: :ref:`ROUTER40<reg-ROUTER40>` to :ref:`ROUTER44<reg-ROUTER44>`

x = 0..8

Layer x monitor bus tag address. The 4 bits of the LxMTAG register are appended as MSBs to the layer output
spike data before it is sent to the monitor bus (see :ref:`monitor-bus-encoding`).
