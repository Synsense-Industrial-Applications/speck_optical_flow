Detailed Signal Description
***************************

.. _rbits-DMOEN:

DMOEN (DVS_Mon)
--------------------------

Enables the DVS Monitor Bus. When enabled, input messages to the dvs pre-processing block are
forwarded on the :ref:`monitor bus<monitor-bus-encoding>` to the output serial interface *data1* input.

.. note::
    These messages are the *raw* messages coming from the internal DVS or an external sensor
    (Ext DVS Mode) before pre-processing.

.. _rbits-SMOEN:

SMOEN (Spike_Mon)
--------------------------

Enables the DVS Pre-Processing Spike Monitor Bus. When enabled, output messages of the dvs pre-processing block are
forwarded on the :ref:`monitor bus<monitor-bus-encoding>` to the output serial interface *data1* input.

.. _rbits-DSD2EN:

DSD2EN (Spike_Dst2)
--------------------------

Enable forwarding to Destination 2 layer (address defined in bits :ref:`rbits-DSD2`.

.. _rbits-DSD1EN:

DSD1EN (Spike_Dst1)
--------------------------

Enable forwarding to Destination 1 layer (address defined in bits :ref:`rbits-DSD1`.

.. _rbits-DMI:

DMI (diagonal_mirror_en)
--------------------------

Enables mirroring of the input events along the diagonal: when set to '1', it swaps X with Y.


.. _rbits-IM:

IM[2:0] (image_mode)
---------------------

Location: :ref:`DVS0[2:0]<reg-DVS0>`

DVS event filtering. Filters/merges events coming from the DVS Bus (Sensor or External).

+---------+---------------------------------------------------------------------------------------------------------+
| IM[2:0] | Configuration                                                                                           |
+---------+---------------------------------------------------------------------------------------------------------+
| 000     | Pass Events with both polarity (to ON *and* to OFF). Merge all events marking them with Polarity = '1'. |
+---------+---------------------------------------------------------------------------------------------------------+
| 001     | Pass only Events with OFF polarity. Mark all events with Polarity '1'.                                  |
+---------+---------------------------------------------------------------------------------------------------------+
| 010     | Pass only Events with ON polarity. Mark all events with Polarity '1'.                                   |
+---------+---------------------------------------------------------------------------------------------------------+
| 011     | Block *all* events.                                                                                     |
+---------+---------------------------------------------------------------------------------------------------------+
| 1xx     | Pass *all* events and maintain the polarity information.                                                |
+---------+---------------------------------------------------------------------------------------------------------+

.. _rbits-SPSS:

SPSS (sensor_pass)
--------------------------

Pass/Drop Internal DVS Events. If disabled, the internal sensor events are dropped, i.e., not forwarded to the DVS :ref:`pre-processing block<event-pre-processing>`.

This is typically used when sensor data is provided by an external source (Ext DVS Mode).

+------+---------------------------------------------------------+
| SPSS | Configuration                                           |
+------+---------------------------------------------------------+
| '0'  | Drop internal DVS events                                |
+------+---------------------------------------------------------+
| '1'  | Forward internal DVS events to DVS pre-processing block |
+------+---------------------------------------------------------+
