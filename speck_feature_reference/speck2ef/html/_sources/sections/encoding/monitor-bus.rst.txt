Monitor Bus Encoding
====================

The monitor bus provides a monitoring of messages generated at various levels of the Speck2e architecture.
The monitor bus can be enabled by setting register bits :ref:`ININT8:P2SSEL<rbits-P2SSEL>` to `0b0`.
