JTAG Command Reference
======================

The length of the JTAG instruction register is 8 bits.

+------------------+-------+-------------------------------------------------------------------------------------+
| Name             | Value | Description                                                                         |
+------------------+-------+-------------------------------------------------------------------------------------+
| EXTEST           | 0x00  |                                                                                     |
+------------------+-------+-------------------------------------------------------------------------------------+
| IDCODE           | 0x01  | Get Chip JTAG ID.                                                                   |
+------------------+-------+-------------------------------------------------------------------------------------+
| SAMPLE_PRELOAD   | 0x02  |                                                                                     |
+------------------+-------+-------------------------------------------------------------------------------------+
| SET_ADDR         | 0x10  | Set SRAM or Register address for R/W operation.                                     |
+------------------+-------+-------------------------------------------------------------------------------------+
| REGISTER_READ    | 0x11  | Read register at the given address (see :ref:`jtag-reg-r`).                         |
+------------------+-------+-------------------------------------------------------------------------------------+
| REGISTER_WRITE   | 0x12  | Write register at the given address (see :ref:`jtag-reg-w`).                        |
+------------------+-------+-------------------------------------------------------------------------------------+
| SRAM_READ        | 0x13  | Read SRAM at the given address (see :ref:`jtag-sram-r`).                            |
+------------------+-------+-------------------------------------------------------------------------------------+
| SRAM_WRITE       | 0x14  | Write SRAM at the given address (see :ref:`jtag-sram-w`).                           |
+------------------+-------+-------------------------------------------------------------------------------------+
| SCAN_SHIFT       | 0x08  | Connect an Async Logic Scan Chain to TCK/TDI/TDO (see :ref:`jtag-scan-activation`). |
+------------------+-------+-------------------------------------------------------------------------------------+
| SCAN_BLK_SEL     | 0x09  | Set Scan Chain block address (see :ref:`jtag-scan-domains`).                        |
+------------------+-------+-------------------------------------------------------------------------------------+
| SCAN_HSEN_OFF    | 0x0A  | Disable Scan Chain Handshake Enable bit (see :ref:`jtag-scan-activation`).          |
+------------------+-------+-------------------------------------------------------------------------------------+
| SCAN_HSEN_ON     | 0x0B  | Enable Scan Chain Handshake Enable bit (see :ref:`jtag-scan-activation`).           |
+------------------+-------+-------------------------------------------------------------------------------------+
| SCAN_DEN_OFF     | 0x0C  | Disable Scan Chain Data Enable bit (see :ref:`jtag-scan-activation`).               |
+------------------+-------+-------------------------------------------------------------------------------------+
| SCAN_DEN_ON      | 0x0D  | Enable Scan Chain Handshake Data bit (see :ref:`jtag-scan-activation`).             |
+------------------+-------+-------------------------------------------------------------------------------------+
| ASYNC_INPUT_ACK  | 0x20  |                                                                                     |
+------------------+-------+-------------------------------------------------------------------------------------+
| ASYNC_INPUT_READ | 0x21  |                                                                                     |
+------------------+-------+-------------------------------------------------------------------------------------+
| ASYNC_INPUT      | 0x22  |                                                                                     |
+------------------+-------+-------------------------------------------------------------------------------------+
| ASYNC_OUTPUT     | 0x30  |                                                                                     |
+------------------+-------+-------------------------------------------------------------------------------------+
| READOUT          | 0x31  |                                                                                     |
+------------------+-------+-------------------------------------------------------------------------------------+
| SPI_MON          | 0x32  | Readout SPI block internal Monitor data {mon_vld, spi_mon[39:0]}.                   |
+------------------+-------+-------------------------------------------------------------------------------------+
| BYPASS           | 0xFF  | JTAG Bypass mode.                                                                   |
+------------------+-------+-------------------------------------------------------------------------------------+
