
.. _slow-clock:

Internal Slow Clock
===================

In Speck2e, a slow clock signal is internally used to operate a number of
features. In this page, we will provide an overview and references to the various
blocks using this signal.

Clock frequency
***************

In a typical application, the slow clock toggles at a speed of around 10Hz to 10kHz.
The frequency depends on the internal use of the clock, and on the specific application.

Uses
****

The slow clock unifies three timing sources used by different internal blocks:

- Leak clock: the convolutional layers including a Leak circuitry (layers 3 and 4)
  receive the slow clock to trigger a leak operation (see :ref:`leak-operation`).
- DVS Filter clock: the DVS filter uses the slow clock to update its internal state
  (see :ref:`filter-operation`).
- Readout clock: the readout layer uses the slow clock as *moving average clock* to
  time the calculation of output class moving averages (see :ref:`readout-avg-clk`).

Generation
**********

The internal *slow clock* can be provided in two ways:

- External input pin *IO25_CLK_SLOW_I*
- Internally generated by dividing the internal DVS raw event rate

The internally generated clock exploits the random continuous generation of internal DVS
events (even though the generation frequency can fluctuate) by dividing the number of generated
events by a constant (2^14 to 2^17), that is set by the register bits :ref:`SLWCLK[7:6]<rbits-SLWCLK>`.

Configuration
*************

The slow clock configuration can be done via the following registers:

- Slow clock configuration and distribution to readout, leak and filter blocks: :ref:`rbits-SLWCLK`.
- Leak clock enable bit: :ref:`rbits-LKEN`.
- Filter clock enable bit: :ref:`rbits-FCKE`.
