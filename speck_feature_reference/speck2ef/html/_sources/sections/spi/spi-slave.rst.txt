.. _spi-slave-interface:

SPI Slave
=========

The SPI slave interface provides a way to access Register and SRAM memories in Speck2e.
In this page, the protocol and memory addressing schemes are described.

SPI Modes
*********

The following SPI modes are supported:

- Mode 0: CPOL = 0, CPHA = 0
- Mode 3: CPOL = 1, CPHA = 1

SPI clock could run up to 1/16 of main clock frequency, max. 6.25 MHz.

.. _spi-slave-port:

Port
****

+--------------+------+---------------------------+------------+
| Port Name    | Bits | Description               | Remark     |
+--------------+------+---------------------------+------------+
| spi_s_clk_i  | 1    | incoming SPI clock        |            |
+--------------+------+---------------------------+------------+
| spi_s_ss_n_i | 1    | slave select              | low active |
+--------------+------+---------------------------+------------+
| spi_s_mosi_i | 1    | incoming data from master |            |
+--------------+------+---------------------------+------------+
| spi_s_miso_o | 1    | outgoing data to master   |            |
+--------------+------+---------------------------+------------+

**************

      {name: 'spi_sclk_i', wave: '0.hlhl|.hlhlhl|.hl.', phase: -0.1},
      {name: 'spi_mosi_i', wave: 'x3....|..4.....|.x.', phase: -0.0, data: ['instr[23:0]','wdata[7:0]']},
      {name: 'spi_miso_o', wave: 'x2.......5.....|.x.', phase: -0.0, data: ['High Impedance','rdata[7:0]']},
      {},],
      config: {hscale:1},
      foot:{
        text:'SPI single access: CPOL = 0, CPHA = 0 : CLK idle state = low, data sampled on rising edge and shifted on falling edge',
      }
    }

The following table lists the instruction fields from MSB to LSB:

+---------+------+-----------------------------+
| Section | Bits | Function                    |
+---------+------+-----------------------------+
| ACC     | 1    | 0: read (RD), 1: write (WR) |
+---------+------+-----------------------------+
| BM      | 2    | 0-: single mode (SM)        |
|         |      |                             |
|         |      | 10: short burst mode (SBM)  |
|         |      |                             |
|         |      | 11: long burst mode (LBM)   |
+---------+------+-----------------------------+
| BL      | 5    | SBM: burst length           |
|         |      |                             |
|         |      | SM / LBM: don't care        |
+---------+------+-----------------------------+
| ADDR    | 16   | SM: address                 |
|         |      |                             |
|         |      | SBM: starting address       |
|         |      |                             |
|         |      | LBM: don't care             |
+---------+------+-----------------------------+

In single mode (SM) the address can only be one of the first 2^16
addresses.

In short burst mode (SBM) the starting address can only be one of the
first 2^16 addresses.

In long burst mode (LBM) the starting address is specified in register
BADDR (24 bit) and burst length in BLEN (24 bit).

Depending on Access (ACC) and Burs Mode (BM) the following access types
are supported:

* Single write
* Single read
* Burst write
* Burst read

SRAMs
-----

The internal SRAMs can be accessed using SPI through their BIST interfaces.

The addressing of the SRAMs follows the descriptions in :ref:`bist-addressing`. For each SRAM, the
BIST address for the first SRAM word is always 0x00000. When accessing the specific SRAM via SPI,
the starting address listed in the following table matches address 0x00000 of that SRAM.

.. note:: For compatibility reasons, all SRAMs have the same available addressing size.
  Nonetheless, some SRAMs utilize only part of this addressing space. It is responsibility of
  the user to not write unavailable address locations. For example, Leak SRAMs are 1ki elements in
  size, so for Leak SRAM of layer 3, address 0x36_03FF should not be exceeded.

Example
^^^^^^^

We want to write Neuron 137 of Layer 2:

Neuron SRAMs have 16-bit words, so we need to do two writes of 8 bits.

The address of the LSB part of the Neuron data is then:

- Starting SRAM addressing: 0x14_0000
- Neuron in hex: hex(137) = 0x89
- 2x locations per neuron -> starting relative location = 0x89 * 2 = 0x112

Address of 8 LSB = 0x14_0112
Address of 8 MSB = 0x14_0113
