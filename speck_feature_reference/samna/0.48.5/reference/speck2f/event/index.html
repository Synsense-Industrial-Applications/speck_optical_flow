class samna.speck2f.event.Spike

Bases: pybind11_object

Spikes are events that can be consumed and produced by Speck 2f.

When sending spike events to Speck 2f, the properties will be interpreted as the destination layer, feature, x, y that should receive the event. The timestamp property will be used to inject the event into Speck 2f when the external event sequencer timestamp is equal to or greater than the event timestamp.

When receing spike events from Speck 2f the properties should be interpreted as the layer, feature, x, y neuron that generated the spike. The timestamp parameter is the timestamp at which speck2f sent out the event.

property feature

Target/producing feature.

from_json(self: samna.speck2f.event.Spike, arg0: str) → None
property layer

Target layer if it is an input, producing layer if it is an output. As a target layer, it can be [0, 8] which stands for the 9 CNN layers if you want to inject spikes into one of the CNN layers, or 12 if you want to send to the readout layers. If it is an output, the layer in [0, 8] represents the output CNN layer, layer 13 means it is an output from the DVS pre-processing layer if you enabled the monitor_enable.

property timestamp

When receiving a Spike event from a chip the timestamp will be populated with the time at which the event leave the chip.

When sending a Spike event to a chip the timestamp will be used to control when the event will be applied to the chip.

to_json(self: samna.speck2f.event.Spike) → str
property x

Target/producing x coordinate.

property y

Target/producing y coordinate.
