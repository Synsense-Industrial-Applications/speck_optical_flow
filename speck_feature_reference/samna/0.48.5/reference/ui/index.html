property label_interval

0, 2.5, 5.0, 7.5 …

Type:

The span interval that we show labels in x axis. default 2.5 which means labels are going to show at x distances from origin

property label_unit_name

The label unit name. default “s” which is part of the label, like “0s”, “2.5s”, “5.0s”, “7.5s” …

property layout

top left x, top left y, bottom right x, bottom right y. the input values should be between 0 and 1. default 0,0,1,1 which means this plot spreads over whole area of current window.

Type:

The proportion value array of this plot in current window work area

property line_names

A string array which is names of each line.

property max_y_rate

The rate that max y value in y axis keeps than current value peek. usually we set this bigger than 1, default 1 which means max y in y axis is equal to the max y value of all points to show.

property plot_title

Title of plot showing above lines, default empty.

property show_point_circle

Set if show a solid circle at each point, default false.

property show_x_span

X coordinate span to show in the line at the same time, default 10 which means to show all points with x value between the newest X and the newest X substract 10.

property title

Plot title.

property x_label_name
