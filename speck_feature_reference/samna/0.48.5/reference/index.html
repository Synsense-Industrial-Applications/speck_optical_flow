class samna.BasicSinkNode_afe2_event_output_event

Bases: NodeInterface

A basic sink node that captures any output event from a model.

Events received by the sink node will accumulate until they are read or cleaned from the sink with one of its methods.

Please be aware that if you don’t read or clean it repeatedly, it may eat all your memory due to the accumulation of events.

clear_events(self: samna.BasicSinkNode_afe2_event_output_event) → None

Directly clear the event accumulation buffer without returning events.

get_events(self: samna.BasicSinkNode_afe2_event_output_event) → List[samna.afe2.event.Spike | samna.afe2.event.RegisterValue | samna.afe2.event.Version]

Clear the event accumulation buffer and return previously accumulated events.

Returns:

The accumulated events.

Clear the event accumulation buffer and return previously accumulated events. If there are no events available, wait for the specified timeout. If no timeout is specified, wait indefinitely.

Parameters:

timeout (Optional[int]) – The timeout in milliseconds, no timeout by default.

The accumulated events.

Events received by the sink node will accumulate until they are read or cleaned from the sink with one of its methods.

Please be aware that if you don’t read or clean it repeatedly, it may eat all your memory due to the accumulation of events.
