The Samna visualizer can be started in a process separately from the Python process where you import Samna (Note: before import samnagui, we should import samna first). This can be done either via the provided samnagui script by executing

$ samnagui

From a terminal. Or by calling samna.run_visualizer from Python.

samna.run_visualizer(receiver_endpoint, width_proportion, height_proportion)

Opens the visualizer window, set the window size relative to main monitor size, configures its receiving endpoint.

Params:

receiver_endpoint : the visualiser’s endpoint for receiving events (e.g. “tcp://0.0.0.0:33335”).

width_proportion : the rate between window width and workarea width of main monitor, default 0.75, which means this window has a width which equals to 3/4 width of main monitor’s workarea.

height_proportion : the rate between window height and workarea height of main monitor, default 0.75, which means this window has a height which equals to 3/4 height of main monitor’s workarea.

Since the visualizer operates in a separate process, we must utilize the streaming capabilities of the event filter graph to transmit configurations and events to the visualizer. The configurations that the visualizer can accept are listed in Plots.

An full illustration of how to link the streamer to the visualizer can be found in Display Speck 2f DVS Events.

Plots

There are several plots that can be displayed in the visualizer. To configure the plots, a graph with a samna.BasicSourceNode_ui_event node is required.

1import samna
2
3graph = samna.graph.EventFilterGraph()
4config_source, _ = graph.sequential([samna.BasicSourceNode_ui_event(), streamer])

One visualizer can have several different type of plots, and there layout can be configured by the layout keyword argument of each plot, default takes the full space of the visualizer.

Activity Plot

The activity plot is a 2D plot that shows the activity of the DVS events in a 2D grid. The grid size can be configured.

1# create an activity plot with size 128*128 and titled "DVS Layer"
2visualizer_config = samna.ui.VisualizerConfiguration(
3   plots=[samna.ui.ActivityPlotConfiguration(128, 128, "DVS Layer")]
4)
5
6config_source.write([visualizer_config])

Readout Plot

The readout plot is a plot that can display an image which could be used to display the readout of a neuron network. The displayed image is determined by the samna.ui.Readout event sent to the visualizer.

1images = ["example1.jpg", "example2.jpg"]
2
3# create a readout plot titled "Readout" with two images
4visualizer_config = samna.ui.VisualizerConfiguration(
5   plots=[samna.ui.ReadoutPlotConfiguration("Readout", images)]
6)
7
8config_source.write([visualizer_config])

Line Plot

The line plot is a type of plot capable of presenting a line graph, which is utilized to showcase the variations of certain values over time. However, you can’t use create this plot directly, but use Spike Count Plot and Power Measurement Plot instead.

Spike Count Plot

This is an implementation of Line Plot dedicated to display the spike count changes over time sent as samna.ui.SpikeCount.

 1feature_names = ["Closed", "Open"]
 2
 3# create a line plot to display the Spike count changes over time.
 4visualizer_config = samna.ui.VisualizerConfiguration(
 5   plots=[samna.ui.SpikeCountPlotConfiguration(
 6               title="Spike Count",
 7               channel_count= len(feature_names),
 8               line_names= feature_names,
 9               layout= [0, 0, 1, 1],
10               show_x_span=25,
11               label_interval=2.5,
12               max_y_rate=1.2,
13               show_point_circle=True,
14               default_y_max=10,
15   )]
16)
17
18config_source.write([visualizer_config])

Please check samna.ui.SpikeCountPlotConfiguration for more details.

Power Measurement Plot

This is an implementation of Line Plot dedicated to display the power measurement changes over time sent as samna.ui.Measurement. It have the same interface as Spike Count Plot.`

Please check samna.ui.PowerMeasurementPlotConfiguration for more details.

Frame Plot

The frame plot is a type of plot capable of presenting a frame sent through samna.events.Frame event.

1# create a frame plot titled "Frame"
2visualizer_config = samna.ui.VisualizerConfiguration(
3   plots=[samna.ui.FramePlotConfiguration("Frame")]
4)
5
6config_source.write([visualizer_config])

Open Multiple Visualizers

It is possible to open multiple visualizers, each with its own streamer endpoint.

 1import sys, os
 2from threading import Thread
 3
 4def open_visualizer(width_proportion, height_proportion, receiver_endpoint):
 5     # start visualizer in a isolated process which is required on mac, instead of a sub process.
 6     gui_cmd = f"import samna, samnagui; samnagui.run_visualizer('{receiver_endpoint}', {width_proportion}, {height_proportion})"
 7     os_cmd = f'{sys.executable} -c "{gui_cmd}"'
 8     print("Visualizer start command: ", os_cmd)
 9     gui_thread = Thread(target=os.system, args=(os_cmd,))
10     gui_thread.start()
11
12     return gui_thread
13
14streamer_endpoint_1 = "tcp://0.0.0.0:40001"
15streamer_endpoint_2 = "tcp://0.0.0.0:40002"
16width_proportion = 0.75
17height_proportion = 0.75
18
19viz_process_1 = open_visualizer(width_proportion, height_proportion, streamer_endpoint_1)
20viz_process_2 = open_visualizer(width_proportion, height_proportion, streamer_endpoint_2)

To forward events to the visualizer, they need to be sent to the streamer endpoint of that visualizer.
