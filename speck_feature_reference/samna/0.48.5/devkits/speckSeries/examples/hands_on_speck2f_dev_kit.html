Hands On Speck 2f Development Kit

This is a complete example that provides basic steps on how to “light up” the development kit, receive events from the chip, send events to the chip, and visualize the DVS events.

A more concise example can be found in Display Speck 2f DVS Events.

Please ensure you followed the Install instructions and connected the development kit to the USB 3 port with a USB 3.0 cable.

Open a Development Kit

We can easily open a specific device by its device_type_name, for Speck 2f development kits, it can be Speck2fDevKit for Speck 2f development kit, or Speck2fModuleDevKit for Speck 2f module development kit.

1import samna
2
3try:
4    board = samna.device.open_device("Speck2fDevKit")
5except:
6    board = samna.device.open_device("Speck2fModuleDevKit")

For more details, please check Device Controller.

Read/Write From/To The Speck 2f

To read/write from/to the Speck 2f chip, it is necessary to create at least one sink_node and one source_node. There are two ways to create them, either directly instantiate them from the chip model, or create them manually and use a graph to connect to the model.

Note

The sink node buffers all the events it receives until you clear them or read the events. Otherwise, due to the accumulation of events, it could consume all the memory.

Usually we can use filters to reject unwanted events reach the sink node, like the Speck2fOutputEventTypeFilter node used in Create Manually section. But if instantiate it from the chip model, then it receives all events.

Instantiate From The Chip

This is the easiest way to create the sink_node and source_node, but in this way you can’t add filters between the nodes and the chip to process the events.

 1# create a sink node to receive events from the Speck 2f
 2sink_node = samna.graph.sink_from(board.get_model_source_node())
 3
 4# create a source node to send events to the Speck 2f
 5source_node = samna.graph.source_to(board.get_model_sink_node())
 6
 7# Read the first register
 8source_node.write([samna.speck2f.event.ReadRegisterValue(0x0)])
 9
10# a blocking call to wait for 1 event
11print(sink_node.get_n_events(1)) # [speck2f::event::RegisterValue(address=0, data=241)]

Create Manually

With a graph, filters can be used to process events before reaching the final destination. All available filters are listed in Filters.

 1graph = samna.graph.EventFilterGraph()
 2
 3# add a event type filter to let only a specific type to pass
 4_, event_type_filter, sink_node = graph.sequential([board.get_model_source_node(),
 5                                                    "Speck2fOutputEventTypeFilter",
 6                                                    samna.BasicSinkNode_speck2f_event_output_event()])
 7# only pass samna.speck2f.event.RegisterValue event
 8event_type_filter.set_desired_type("speck2f::event::RegisterValue")
 9
10source_node, _ = graph.sequential([samna.BasicSourceNode_speck2f_event_input_event(), board.get_model_sink_node()])
11
12# graph has to start first
13graph.start()
14
15# Read the first register
16source_node.write([samna.speck2f.event.ReadRegisterValue(0x0)])
17
18# a blocking call to wait 1 events
19print(sink_node.get_n_events(1)) # [speck2f::event::RegisterValue(address=0, data=241)]

Setup The Visualizer

The Visualizer is a built-in GUI dedicated to displaying DVS events. It is necessary to launch the GUI in a separate process and direct the DVS events to it.

Start Visualizer

 1import socket
 2import sys, os
 3from threading import Thread
 4
 5def free_port():
 6    """
 7    Determines a free port using sockets.
 8    """
 9    free_socket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
10    free_socket.bind(('0.0.0.0', 0))
11    free_socket.listen(5)
12    port = free_socket.getsockname()[1]
13    free_socket.close()
14
15    return port
16
17# the visualizer will receive from this endpoint
18streamer_endpoint = "tcp://0.0.0.0:" + str(free_port())
19width_proportion = 0.75
20height_proportion = 0.75
21
22# start visualizer in a isolated process which is required on mac, instead of a sub process.
23gui_cmd = f"import samna, samnagui; samnagui.run_visualizer('{streamer_endpoint}', {width_proportion}, {height_proportion})"
24os_cmd = f'{sys.executable} -c "{gui_cmd}"'
25print("Visualizer start command: ", os_cmd)
26gui_thread = Thread(target=os.system, args=(os_cmd,))
27gui_thread.start()

Direct Events To The Visualizer

To direct events to the visualizer, a graph is necessary because we need to use filters:

  • Speck2fDvsToVizConverter: convert samna.speck2f.event.Spike and samna.speck2f.event.DvsEvent to samna.ui.DvsEvent.

  • VizEventStreamer: stream the visualizer acceptable events to the visualizer.

 1to_vis_graph = samna.graph.EventFilterGraph()
 2
 3_, _, streamer = to_vis_graph.sequential(
 4    [board.get_model_source_node(), "Speck2fDvsToVizConverter", "VizEventStreamer"]
 5)
 6
 7# create a node to send visualizer configurations
 8config_source, _ = to_vis_graph.sequential([samna.BasicSourceNode_ui_event(), streamer])
 9
10# set the streamer endpoint the same as the endpoint set when creating the visualizer
11streamer.set_streamer_endpoint(streamer_endpoint)
12if streamer.wait_for_receiver_count() == 0:
13    raise Exception(f'connecting to visualizer on {streamer_endpoint} fails')
14
15# create a 128*128 resolution activity plot to display the DVS events
16visualizer_config = samna.ui.VisualizerConfiguration(
17    plots=[samna.ui.ActivityPlotConfiguration(128, 128, "DVS Layer")]
18)
19
20# start the graph
21to_vis_graph.start()
22
23# send the configurations to the visualizer
24config_source.write([visualizer_config])

Config Speck 2f chip

After setting up the sink and source node, we are ready to send and receive events to/from the Speck 2f. But in order to get some events from the Speck 2f, we need to configure the Speck 2f to do so.

The very basic approach to get anything from the Speck 2f is to enable the monitoring of the DVS Pre-Processing Layer. For more configurations, please check How to Configure Chip.

1config = samna.speck2f.configuration.SpeckConfiguration()
2
3# enable the monitoring of the dvs pre-processing layers
4config.dvs_layer.monitor_enable = True
5
6# apply the configuration to the Speck 2f
7board.get_model().apply_configuration(config)

After apply_configuration, you should be able to see DVS events on the visualizer.
