Record Speck 2f DVS

Content

  • Setup Visualizer

  • Record DVS Events

Here is a simple example of how to record the DVS events from the Speck 2f development kit. For how to use the recorded events, please refer to Using Recorded Events On Speck 2f example.

Setup Visualizer

First we have to setup the visualizer similar to Display Speck 2f DVS Events. However, we don’t add gui_process.join() and graph.stop() because we don’t want them to block our code.

 1import samna
 2import sys
 3import os
 4from threading import Thread
 5
 6def open_speck2f_dev_kit():
 7    devices = [
 8        device
 9        for device in samna.device.get_unopened_devices()
10        if device.device_type_name.startswith("Speck2f")
11    ]
12    assert devices, "Speck2f board not found"
13
14    return samna.device.open_device(devices[0])
15
16
17def build_samna_event_route(dk, graph, endpoint):
18    # build a graph in samna to show dvs
19    _, _, streamer = graph.sequential(
20        [dk.get_model_source_node(), "Speck2fDvsToVizConverter", "VizEventStreamer"]
21    )
22
23    config_source, _ = graph.sequential([samna.BasicSourceNode_ui_event(), streamer])
24
25    streamer.set_streamer_endpoint(endpoint)
26    if streamer.wait_for_receiver_count() == 0:
27        raise Exception(f'connecting to visualizer on {endpoint} fails')
28
29    visualizer_config = samna.ui.VisualizerConfiguration(
30        plots=[samna.ui.ActivityPlotConfiguration(128, 128, "DVS Layer")]
31    )
32
33    config_source.write([visualizer_config])
34
35
36def open_visualizer(width_proportion, height_proportion, receiver_endpoint):
37    # start visualizer in a isolated process which is required on mac, instead of a sub process.
38    gui_cmd = f"import samna, samnagui; samnagui.run_visualizer('{receiver_endpoint}', {width_proportion}, {height_proportion})"
39    os_cmd = f'{sys.executable} -c "{gui_cmd}"'
40    print("Visualizer start command: ", os_cmd)
41    gui_thread = Thread(target=os.system, args=(os_cmd,))
42    gui_thread.start()
43
44    return gui_thread
45
46
47streamer_endpoint = "tcp://0.0.0.0:40001"
48width_proportion = 0.75
49height_proportion = 0.75
50
51gui_process = open_visualizer(width_proportion, height_proportion, streamer_endpoint)
52
53dk = open_speck2f_dev_kit()
54
55# route events
56graph = samna.graph.EventFilterGraph()
57build_samna_event_route(dk, graph, streamer_endpoint)
58
59graph.start()
60
61# modify configuration
62config = samna.speck2f.configuration.SpeckConfiguration()
63# enable dvs event monitoring
64config.dvs_layer.monitor_enable = True
65dk.get_model().apply_configuration(config)

Record DVS Events

Following the above code, we could create a function to record the DVS events given a name and duration.

Here we use a simple encoding to save the events to a file. The events are saved in the following order: x, y, feature, timestamp. The x, y, feature and timestamp are all 4 bytes long (little endian), so the file size is 16 bytes per event.

 1import time
 2stopwatch = dk.get_stop_watch()
 3
 4def record_dvs(name: str, duration: int):
 5    """
 6    Record DVS events for a given duration and save to a file.
 7    """
 8    # create a sink node to receive the DVS events
 9    sink = samna.graph.sink_from(dk.get_model_source_node())
10
11    # start timestamp from 0
12    stopwatch.start(True)
13
14    # clear events already in the sink node
15    sink.clear_events()
16
17    time.sleep(duration)
18
19    events = sink.get_events()
20
21    with open(name, "wb") as f:
22        for event in events:
23            if isinstance(event, samna.speck2f.event.Spike):
24                f.write((event.x).to_bytes(4, byteorder = 'little'))
25                f.write((event.y).to_bytes(4, byteorder = 'little'))
26                f.write((event.feature).to_bytes(4, byteorder = 'little'))
27                f.write((event.timestamp).to_bytes(4, byteorder = 'little'))

Note

The sink node is created as a local variable in the function, so it is destroyed after the function returns to prevent it takes all memory.
