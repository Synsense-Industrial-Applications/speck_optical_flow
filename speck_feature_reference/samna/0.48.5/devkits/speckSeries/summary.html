Speck series

Speck 2f

Slow Clock

The Speck 2f development kit offers a clock source originating from the on - board FPGA. This clock source can be utilized as the external slow clock for the Speck 2f.

1# get the io module of the chip,
2# which controls the IO pins of the chip
3io = board.get_io_module()
4
5# set the slow clock rate to 100Hz for example
6io.set_slow_clk_rate(100)
7
8# enable the slow clock
9io.set_slow_clk(True)
