Xylo-IMU Boards

The XyloImuTestBoard is built around the Xylo-IMU chip, complemented by various peripherals to extend its functionality. The board includes an FPGA-based motherboard that facilitates communication over USB, and a daughterboard that houses the Xylo-IMU chip.

Integrated on the daughterboard is an MC3632 accelerometer, which can be accessed independently of the Xylo chip for additional sensing capabilities.

The board also features an ADC, enabling on-board power measurement for more comprehensive performance monitoring.
