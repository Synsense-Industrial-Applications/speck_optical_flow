##################
XyloAudio 3 Boards
##################

The ``XyloAudio3TestBoard`` features a XyloAudio 3 chip integrated with additional peripherals for
enhanced functionality. It comprises an FPGA-based motherboard that manages communication via USB,
and a daughterboard housing the XyloAudio 3 chip.

The board is equipped with both analog and digital microphones.
**Important:** when working with the microphones, the correct ones needs to be selected via a switch.

Additionally, an ADC is included to enable on-board power measurements.
