==========
Slow Clock
==========

The Speck 2f development kit offers a clock source originating from the on - board FPGA. 
This clock source can be utilized as the external slow clock for the Speck 2f. 

.. code-block:: python
   :linenos:

   # get the io module of the chip, 
   # which controls the IO pins of the chip
   io = board.get_io_module()

   # set the slow clock rate to 100Hz for example 
   io.set_slow_clk_rate(100)

   # enable the slow clock
   io.set_slow_clk(True)
