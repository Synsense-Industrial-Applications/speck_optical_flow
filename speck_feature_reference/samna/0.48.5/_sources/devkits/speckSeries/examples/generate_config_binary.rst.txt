##################################################
Export your model from dev kit to embedded devices
##################################################

Depending on how Speck is configured in the embedded system, there are two options:

1. Speck reads configuration from an external flash through its SPI master interface.
2. The controller (MCU) configures Speck through its SPI slave interface.

Assume you already have the desired configuration stored in ``config``.

==============================================
Option 1: Generate a binary for external flash
==============================================

Speck 2f can boot from an external flash through its SPI master interface. Users can
use Samna on the development kit to evaluate different configurations and then generate
the binary for external flash.

Here is a basic example that generates the configuration binary and writes it to a file.
The generated binary is always 354 KB.

.. code-block:: python
    :linenos:

    binary = samna.speck2f.configuration_to_flash_binary(config)
    with open("speck2f_config_flash.bin", "wb") as f:
        f.write(binary)

This approach is straightforward. However, it requires a physical external flash in the system, 
and updating the model requires extra flashing steps.

===========================================================
Option 2: Generate a C array to configure through SPI slave
===========================================================

This module takes the configuration event stream generated by ``samna`` and outputs a
``.bin`` or ``.c`` file that is suitable for embedded systems configuring Speck through
the SPI slave interface, similar to development kits.

In Python, the process is:

- Capture the full configuration stream from the dev kit into a binary stream.
- Compress the original stream by encoding consecutive zeros with variable-length encoding.
- Convert the compressed binary stream into a C ``char`` array that can be compiled into
  the embedded system firmware.

On the embedded system, this array (typically stored in internal flash) is decoded, and
the recovered stream is sent through SPI.

-------------------
Example Python code
-------------------

The data flow is:

:code:`devkit_script.py ---config---> generate_spi_stream() ---stream---> merge_and_compress() ---stream_compressed---> my_speck_model.c`

.. code-block:: python
    :linenos:

    import subprocess


    def generate_spi_stream(dk, config):

        def is_spi_packet(packet):
            RAW_DATA_FORMAT = 0x40
            RAW_DATA_FORMAT_MASK = 0xC0
            LINK_PACKET_FORMAT = 0xE
            return all(isinstance(x, int) for x in packet) and (packet[1] & RAW_DATA_FORMAT_MASK) == RAW_DATA_FORMAT and packet[3] == LINK_PACKET_FORMAT

        hook = dk.make_unifirm_hook()

        # Clear
        hook.poll_tx()

        dk.get_model().apply_configuration(config)

        packets = hook.poll_tx()

        stream = bytearray()

        for packet in packets:
            if is_spi_packet(packet):
                data = packet[8:]
                stream.append(len(data))
                stream.extend(data)

        return stream


    def encode_zeros(data):
        output = bytearray()
        i = 0
        length = len(data)

        while i < length:
            if data[i] == 0:
                count = 0
                while i < length and data[i] == 0:
                    count += 1
                    i += 1
                assert(count < (3 << 16))
                if count < 3:
                    output.extend([0x00] * count)
                else:
                    output.extend([0x00] * 3)
                    if count < 256:
                        output.append(count)
                    else:
                        output.extend(count.to_bytes(3, byteorder='big'))
            else:
                output.append(data[i])
                i += 1

        return output


    def try_append_burst(output, burst_len, burst_addr, burst_data):

        if burst_len > 0:

            spi_data = bytearray()
            spi_data.extend([0xC6, 0x00, 0x01])
            spi_data.extend(burst_len.to_bytes(3, byteorder='little'))
            spi_data.extend(burst_addr.to_bytes(3, byteorder='little'))
            spi_data.extend([0xE0, 0x00, 0x00])
            spi_data.extend(burst_data)

            compressed_data = encode_zeros(spi_data)
            compressed_packet_length = len(compressed_data)
            assert(compressed_packet_length < (1 << 24))

            zero_cnt = 0
            original_length = 0
            i = 0
            while i < compressed_packet_length:
                if compressed_data[i] == 0:
                    i += 1
                    original_length += 1
                    zero_cnt += 1
                    if zero_cnt == 3:
                        l = int(compressed_data[i])
                        i += 1
                        if l < 3:
                            l = (l << 16) | int.from_bytes(compressed_data[i:i+2], byteorder='big')
                            i += 2
                        original_length += l - 3
                        zero_cnt = 0
                else:
                    i += 1
                    original_length += 1
                    zero_cnt = 0
            assert(i == compressed_packet_length)
            assert(original_length == len(spi_data))

            output.extend(compressed_packet_length.to_bytes(4, byteorder='big'))
            output.extend(compressed_data)


    def merge_and_compress(data):

        output = bytearray()

        i = 0
        length = len(data)

        packet_length = None
        merged_burst_len = 0
        merged_burst_addr = None
        merged_burst_data = bytearray()

        while i < length:
            packet_length = data[i]

            i += 1
            header = int.from_bytes(data[i:i+3], byteorder='big')
            if header == 0xC60001:
                i += 3
                burst_len = int.from_bytes(data[i:i+3], byteorder='little')
                assert(burst_len == packet_length - 12)
                i += 3
                burst_addr = int.from_bytes(data[i:i+3], byteorder='little')
                i += 3
                assert(int.from_bytes(data[i:i+3], byteorder='big') == 0xE00000)
                i += 3
                burst_data = bytearray(data[i:i+burst_len])
                i += burst_len
                if merged_burst_len > 0 and merged_burst_addr + merged_burst_len == burst_addr:
                    merged_burst_len += burst_len
                    merged_burst_data.extend(burst_data)
                else:
                    try_append_burst(output, merged_burst_len, merged_burst_addr, merged_burst_data)
                    merged_burst_len = burst_len
                    merged_burst_addr = burst_addr
                    merged_burst_data = burst_data
            else:
                try_append_burst(output, merged_burst_len, merged_burst_addr, merged_burst_data)
                merged_burst_len = 0
                compressed_data = encode_zeros(data[i:i+packet_length])
                compressed_packet_length = len(compressed_data)
                output.extend(compressed_packet_length.to_bytes(4, byteorder='big'))
                output.extend(compressed_data)
                i += packet_length
        assert(i == length)
        try_append_burst(output, merged_burst_len, merged_burst_addr, merged_burst_data)

        # Toggle reset to enable Speck
        for reset_register_value in [0x01, 0x81, 0xc1, 0xe1, 0xf1]:
            output.extend([0x00, 0x00, 0x00, 0x04, 0x80, 0x00, 0x00, reset_register_value])

        output = len(output).to_bytes(4, byteorder='big') + output

        return output


    def apply_configuration(dk, config, raw_bin_path=None, compressed_bin_path=None, c_path=None, c_array_name="speck_config"):

        stream = generate_spi_stream(dk, config)

        if raw_bin_path is not None:
            with open(raw_bin_path, 'wb') as f:
                f.write(stream)

        stream_compressed = merge_and_compress(stream)

        if compressed_bin_path is not None or c_path is not None:
            if compressed_bin_path is None:
                compressed_bin_path = c_path + '.bin'
            with open(compressed_bin_path, "wb") as f:
                f.write(stream_compressed)

        if c_path is not None:

            cmd = [
                "bin2c",
                compressed_bin_path,
                "-n", c_array_name,
                "-c"
            ]

            with open(c_path, "w") as f:
                subprocess.run(cmd, stdout=f, check=True)

-----
Usage
-----

Simply replace:

.. code-block:: python

    dk.get_model().apply_configuration(config)

in your original dev-kit script with:

.. code-block:: python

    apply_configuration(dk, config, c_path="my_speck_model.c")

The generated file ``my_speck_model.c`` contains the C array for the embedded device.

----------------
Process overview
----------------

The Python example above has three main steps:

1. Merge as many write bursts as possible.
2. Compress consecutive zeros in the data.
3. Convert the resulting binary file into a C ``char`` array.

-------------------------------------------------------------------
Original configuration stream (``stream`` in the code above) format
-------------------------------------------------------------------

The binary stream generated by ``generate_spi_stream`` consists of SPI slave waveform
packets. Each packet contains:

- A 1-byte header indicating the packet length ``n`` (bytes).
- ``n`` bytes of data to be sent directly through the SPI slave interface (MOSI) by
  ``samna``.

+-----------------+-------------------------+----------+-------------------------+----------+
| Description     | Length of 1 SPI stream  | Stream   | Length of 1 SPI stream  | Stream   |
+-----------------+-------------------------+----------+-------------------------+----------+
| Number of bytes | 1                       | ...      | 1                       | ...      |
+-----------------+-------------------------+----------+-------------------------+----------+

------------------------------------------------------------------
Compressed stream (``stream_compressed`` in the code above) format
------------------------------------------------------------------

The compressed stream generated by ``merge_and_compress``, written to the output binary
or C ``char`` array (for example, ``my_speck_model.c``), contains:

- A 4-byte header indicating the total data length.
- A series of compressed SPI slave waveform packets, each containing:

  - A 4-byte header indicating packet length ``n``.
  - ``n`` bytes of data, which are decompressed and sent through the SPI slave interface
    (MOSI) by the MCU.

+-----------------+-----------------------+----------------------------+-----------------------+-----+----------------------------+----------------------+
| Description     | Length of whole data  | Length of first SPI packet | First SPI packet data | ... | Length of last SPI packet  | Last SPI packet data |
+-----------------+-----------------------+----------------------------+-----------------------+-----+----------------------------+----------------------+
| Number of bytes | 4                     | 4                          | as specified          | ... | 4                          | as specified         |
+-----------------+-----------------------+----------------------------+-----------------------+-----+----------------------------+----------------------+

------------------
Encoding algorithm
------------------

Consecutive zeros are encoded using variable-length encoding:

.. code-block:: text

    0x00 -> 0x00
    0x00, 0x00 -> 0x00, 0x00
    0x00, 0x00, 0x00 -> 0x00, 0x00, 0x00, 0x03
    0x00, 0x00, 0x00, 0x00 -> 0x00, 0x00, 0x00, 0x04
    ...
    0x00 repeated 0xFF times -> 0x00, 0x00, 0x00, 0xFF
    0x00 repeated 0x100 times -> 0x00, 0x00, 0x00, 0x00, 0x01, 0x00
    ...
    0x00 repeated 0x2FFFF times -> 0x00, 0x00, 0x00, 0x02, 0xFF, 0xFF

Note: The maximum consecutive memory in SRAM is 2^17 (0x20000) bytes, so this encoding is sufficient.

--------------
Example C code
--------------

The following example demonstrates decoding and sending the configuration to the SPI slave:

.. code-block:: c

    // Speck SPI slave interface uses mode 0 (CPOL = 0, CPHA = 0)

    #define SIZE_OF_TOTAL_LENGTH 4U // 4 bytes
    #define SIZE_OF_BSP_SPI_PACKET_LENGTH 4U // 4 bytes
    #define RB_LOW_MS 500 // duration (ms) for RB to be low (active)
    #define WAIT_AFTER_RB_HIGH_MS 5000 // must be >= 10000 / CLK_I_FREQ_MHZ (2 in this example)
    #define BSP_SPI_PERIOD_US 8U // must be >= 16 / CLK_I_FREQ_MHZ (2 in this example)

    void bsp_spi_send_byte(uint8_t data)
    {
        // Simulate SPI MOSI with GPIO, mode 0
        for (int j = 0; j < 8; j++)
        {
            if (data & 0x80)
            {
                SPI_MOSI_H();
            }
            else
            {
                SPI_MOSI_L();
            }
            delay_us(BSP_SPI_PERIOD_US / 2); // user-defined delay function in microseconds
            SPI_CLK_H();
            delay_us(BSP_SPI_PERIOD_US / 2);
            SPI_CLK_L();
            data <<= 1;
        }
    }

    void bsp_spi_write(uint8_t *w_data, uint32_t len)
    {
        uint8_t data;
        uint32_t zero_cnt = 0;
        uint32_t zero_remain = 0;
        // Start SPI transaction by pulling down CSN
        SPI_CSN_L();
        // Decode and send bytes
        for (int i = 0; i < len || zero_remain > 0; bsp_spi_send_byte(data))
        {
            if (zero_remain == 0)
            {
                data = w_data[i++];
                if (data == 0)
                {
                    zero_cnt++;
                    if (zero_cnt == 3)
                    {
                        zero_cnt = 0;
                        zero_remain = w_data[i++];
                        if (zero_remain < 3)
                        {
                            zero_remain <<= 8;
                            zero_remain |= w_data[i++];
                            zero_remain <<= 8;
                            zero_remain |= w_data[i++];
                        }
                        zero_remain -= 3;
                    }
                }
                else
                {
                    zero_cnt = 0;
                }
            }
            else
            {
                data = 0;
                zero_remain--;
            }
        }
        // End SPI transaction by pulling up CSN
        delay_us(BSP_SPI_PERIOD_US / 2);
        SPI_CSN_H();
    }

    static void Speck_Init(void)
    {
        // Initialize SPI slave
        SPI_CLK_L();
        SPI_CSN_H();

        // Reset Speck
        RB_L();
        delay_ms(RB_LOW_MS); // user-defined delay function in milliseconds
        RB_H();
        delay_ms(WAIT_AFTER_RB_HIGH_MS);

        // Configure Speck
        extern const uint8_t speck_config[];
        uint32_t total_length = 0;
        uint32_t packet_length = 0;
        uint32_t index = 0;

        // Get total configuration stream length
        for (int i = 0; i < SIZE_OF_TOTAL_LENGTH; i++)
        {
            total_length <<= 8;
            total_length |= speck_config[index++];
        }

        while (total_length > 0)
        {
            // Get length of one SPI transaction
            packet_length = 0;
            for (int i = 0; i < SIZE_OF_BSP_SPI_PACKET_LENGTH; i++)
            {
                packet_length <<= 8;
                packet_length |= speck_config[index++];
            }
            total_length -= SIZE_OF_BSP_SPI_PACKET_LENGTH;

            // Send SPI waveform
            bsp_spi_write(speck_config + index, packet_length);
            total_length -= packet_length;
            index += packet_length;
        }
    }
