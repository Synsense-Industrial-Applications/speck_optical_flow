#################################
Using Recorded Events On Speck 2f
#################################

.. contents:: Topics
   :local:
   :depth: 2

This example shows how to send recorded events to Speck 2f. 
For how to record events, please refer to :ref:`Record Speck 2f DVS` example.

****************
Setup Visualizer 
****************

First we could setup the visualizer similar to :ref:`Record Speck 2f DVS` example, 
but this time we don't let raw dvs events pass to the :ref:`DVS pre-processor layer <speck_2f_dvs_layer>`.

Please note that the :attr:`config.dvs_layer.pass_sensor_events <samna.speck2f.configuration.DvsLayerConfig.pass_sensor_events>` has to be set to 
``False`` after enable the :attr:`config.dvs_layer.monitor_enable <samna.speck2f.configuration.DvsLayerConfig.monitor_enable>`. 
For more details, please check :ref:`DVS Layer <speck_2f_dvs_layer>` section.

.. code-block:: python
    :linenos:

    import samna
    import sys
    import os
    from threading import Thread

    def open_speck2f_dev_kit():
        devices = [
            device
            for device in samna.device.get_unopened_devices()
            if device.device_type_name.startswith("Speck2f")
        ]
        assert devices, "Speck2f board not found"

        return samna.device.open_device(devices[0])


    def build_samna_event_route(dk, graph, endpoint):
        # build a graph in samna to show dvs
        _, _, streamer = graph.sequential(
            [dk.get_model_source_node(), "Speck2fDvsToVizConverter", "VizEventStreamer"]
        )

        config_source, _ = graph.sequential([samna.BasicSourceNode_ui_event(), streamer])

        streamer.set_streamer_endpoint(endpoint)
        if streamer.wait_for_receiver_count() == 0:
            raise Exception(f'connecting to visualizer on {endpoint} fails')
        
        visualizer_config = samna.ui.VisualizerConfiguration(
            plots=[samna.ui.ActivityPlotConfiguration(128, 128, "DVS Layer")]
        )

        config_source.write([visualizer_config])


    def open_visualizer(width_proportion, height_proportion, receiver_endpoint):
        # start visualizer in a isolated process which is required on mac, instead of a sub process.
        gui_cmd = f"import samna, samnagui; samnagui.run_visualizer('{receiver_endpoint}', {width_proportion}, {height_proportion})"
        os_cmd = f'{sys.executable} -c "{gui_cmd}"'
        print("Visualizer start command: ", os_cmd)
        gui_thread = Thread(target=os.system, args=(os_cmd,))
        gui_thread.start()

        return gui_thread


    streamer_endpoint = "tcp://0.0.0.0:40001"
    width_proportion = 0.75
    height_proportion = 0.75

    gui_process = open_visualizer(width_proportion, height_proportion, streamer_endpoint)

    dk = open_speck2f_dev_kit()

    # route events
    graph = samna.graph.EventFilterGraph()
    build_samna_event_route(dk, graph, streamer_endpoint)

    graph.start()

    # modify configuration
    config = samna.speck2f.configuration.SpeckConfiguration()
    # enable dvs event monitoring
    config.dvs_layer.monitor_enable = True
    # not pass raw dvs events to the pre-processor layer 
    config.dvs_layer.pass_sensor_events = False
    dk.get_model().apply_configuration(config)

**********************************
Direct Recorded Events to Speck 2f 
**********************************

Now we can send recorded events to Speck 2f :ref:`DVS pre-processing layer <speck_2f_dvs_layer>` using binary data
generated by the :ref:`Record Speck 2f DVS <record_speck_2f_dvs>` example. You can also send them to CNN layers 
by using :class:`samna.speck2f.event.Spike` event with :attr:`~samna.speck2f.event.Spike.layer` set to the corresponding layer.

.. list-table::
    :header-rows: 1

    * - X
      - Y
      - Feature/Polarity
      - Timestamp
    * - 4 bytes
      - 4 bytes
      - 4 bytes
      - 4 bytes

The stopwatch is started and reset to 0, and a 1s delay is added to all events, 
to ensure that the timestamp inside the FPGA is smaller then the first event so 
events are forwarded to the Speck 2f in real time interval. For more details, please
check :ref:`Timestamp` section.

.. code-block:: python
    :linenos:

    import struct

    def load_recorded_events(file_name):
        events = []
        # add 1s time delay to all events
        TIME_DELAY = 1000000 # 1s

        with open(file_name, 'rb') as f:
            while True:
                # every event has 16 bytes
                event_data = f.read(16)
                if len(event_data) == 16:
                    x, y, p, t = struct.unpack('<4I', event_data)
                    t &= 0xffffffff
                    events.append(samna.speck2f.event.DvsEvent( x = x, y = y, p = p, timestamp = t + TIME_DELAY))
                else:
                    break
        return events

    source = samna.graph.source_to(dk.get_model().get_sink_node())

    events = load_recorded_events("test.bin")

    stopwatch = dk.get_stop_watch()

    # start timestamp from 0
    stopwatch.start(reset = True)

    source.write(events)
