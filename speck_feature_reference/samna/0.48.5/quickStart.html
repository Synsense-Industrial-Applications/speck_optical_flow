Quick Start

This guide provides step-by-step instructions for managing devices, configuring settings, and handling event streams using Samna.

Prerequisites

  • Ensure devices are connected via USB 3.0-compatible USB-C cables.

Manipulate Devices

For detailed description please check Device Controller.

Discover Devices

All SynSense devices can be discovered by the following methods:

1# Get all supported devices that are currently connected to the machine.
2devices = samna.device.get_all_devices()
3
4# Get all devices that have been opened in this process.
5devices = samna.device.get_opened_devices()
6
7# Get all supported devices that are currently connected to the machine and are not in use by any process.
8devices = samna.device.get_unopened_devices()

Open Devices

Open by Device Instance

Use this if you want to dynamically detect and open devices:

1# List all connected unopened devices
2devices = samna.device.get_unopened_devices()
3
4# Open the first detected device
5if devices:
6    my_device = samna.device.open_device(devices[0])

Open by Device Name

Use this to explicitly open a specific device type (e.g., Speck2f Dev Kit):

1# Open the first Speck2f Dev Kit
2board = samna.device.open_device("Speck2fDevKit:0")

Note

  • Device names follow the format "<DeviceType>:<Index>" (e.g., "DvXplorer:0").

  • For a list of supported devices, refer to Supported Devices.

Select a Device from Multiple Connected Devices

If multiple devices are connected, filter by type using their device_type_name attribute:

1devices = samna.device.get_unopened_devices()
2
3for dev in devices:
4    if dev.device_type_name == "DvXplorer":
5        my_dvxplorer = samna.device.open_device(dev)
6    elif dev.device_type_name == "Speck2fDevKit":
7        my_dev_kit = samna.device.open_device(dev)

Configuring a Chip

To configure a chip:

  1. Create a configuration object with desired settings.

  2. Apply the configuration to the chip’s model.

In Samna, one chip only has one type of configuration object. For example, Speck2fDevKit, Speck2fModuleDevKit, Speck2fLcc84LoulanBoard, Speck2fCharacterizationBoard, Speck2fCharQiuciBoard and Speck2fModuleLoulanBoard share one type of configuration object: samna.speck2f.configuration.SpeckConfiguration.

Example for Speck2f series:

1# Create a default configuration
2config = samna.speck2f.configuration.SpeckConfiguration()
3
4# modify configuration
5
6# Apply to the chip model
7model = board.get_model()  # Assuming board is the opened chip
8model.apply_configuration(config)

To ensure the proper configuration of the chip, such as enabling any output from it, please refer to the dedicated page of the specific chip model for detailed instructions:

  • How to configure Speck 2f chip

Event Handling with Filter Graphs

Samna uses event filter graphs to process and route events between devices, filters, and sinks. Each samna.graph.EventFilterGraph has it’s own processing thread.

Create a Graph

graph = samna.graph.EventFilterGraph()

Receiving Events from a Chip model

Connect the chip model’s source node to a sink node to collect events. For the available methods of the sink node, please check Sinks.

With a Filter Graph

You have to manually create a sink node, then you have the ability to add filters between the model source and the sink to process the events. For all the available filters, please check Filters.

Here we take Speck2f as an example.

 1graph = samna.graph.EventFilterGraph()
 2
 3_, sink = graph.sequential([board.get_model_source_node(), samna.BasicSinkNode_speck2f_event_output_event()])
 4
 5graph.start()
 6
 7# Read events
 8events = sink.get_events()  # Returns a list of events
 9
10graph.stop()

Without a Filter Graph

In this way there is no graph constructed, so you can’t add filters between the model source and the sink node to process the events.

1# assumes 'board' is an opened device
2sink = samna.graph.sink_from(board.get_model_source_node())
3
4# Read events
5events = sink.get_events()  # Returns a list of events

Sending Events to a Chip

Use a source node to send events to the chip’s sink node:

With a Filter Graph

You have to manually create a source node, then you have the ability to add filters between the source and the model sink to process the events. For all the available filters, please check Filters.

Here we take Speck2f as an example.

1graph = samna.graph.EventFilterGraph()
2
3# manually create a sink node for Speck2f series
4source, _ = graph.sequential([samna.BasicSourceNode_speck2f_event_input_event(), board.get_model_sink_node()])
5
6graph.start()
7
8# Write events
9source.write([event1, event2])

Without a Filter Graph

In this way there is no graph constructed, so you can’t add filters between the source and the model sink node to process the events.

1source = samna.graph.source_to(board.get_model().get_sink_node())
2
3# Write events
4source.write([event1, event2])

Add filters

Samna provides many built-in filters to process events on the fly, for all built-in filters, please check Filters. Different filters have different methods that users can set. Each chip has it’s own set of filters it can use, please make sure you are using the correct filter for the chip.

If the built-in filters can’t meet your needs, you can even write your own filter in C++ with the JIT comes with Samna, please check JIT Filters for more details.

To use a filter, you have to create a graph first.

1graph = samna.graph.EventFilterGraph()
2
3_, event_type_filter, _ = graph.sequential([board.get_model_source_node(), "Speck2fOutputEventTypeFilter", sink])
4
5# Here we use Speck2fOutputEventTypeFilter to let only speck2f::event::RegisterValue event can reach the sink.
6event_type_filter.set_desired_type("speck2f::event::RegisterValue")
7
8graph.start()

Visualization

Launching the Visualizer

Run the visualizer from the terminal:

samnagui -W 0.75 -H 0.75 "tcp://0.0.0.0:40000"

Or programmatically:

# samnagui must be imported after samna
import samna, samnagui

samnagui.run_visualizer(
   "tcp://0.0.0.0:40000",  # Endpoint
   0.75,                    # Window width scale
   0.75                     # Window height scale
)

Displaying Events in the Visualizer

  1. Stream visualizer configure events to the visualizer via a VizEventStreamer:

    graph = samna.graph.EventFilterGraph()
config_source, streamer = graph.sequential([samna.BasicSourceNode_ui_event(), "VizEventStreamer"])
streamer.set_streamer_endpoint("tcp://0.0.0.0:40000")  # Match visualizer port

if streamer.wait_for_receiver_count() == 0:
  raise Exception(f'connecting to visualizer fails')

  2. Create an activity plot for DVS events:

    config_source.write([
    samna.ui.VisualizerConfiguration(
        plots=[samna.ui.ActivityPlotConfiguration(128, 128, "DVS Activity")]
    )
])

    You can find all supported visualizer configurations in this page.

  3. Stream visualizable events to the visualizer via a VizEventStreamer:

    Convert chip-specific events to visualization events using a node like Speck2fDvsToVizConverter. You can find this converter filter for different chips in Available Filters.

    board = samna.device.open_device("Speck2fDevKit:0")
_, _, streamer = graph.sequential([board.get_model_source_node(), "Speck2fDvsToVizConverter", "VizEventStreamer"])
