Detailed Signal Description
***************************


.. _rbits-SFR:

SFR[1:0] (sramF_read)
----------------------------

Timing Control Filter SRAM - Read Data Ready.

.. note:: The internal Filter SRAM Read timing value is calculated as {SFR1, !(SFR0)}.
    Therefore, to obtain an internal setting of 0b01, the register SFR must be set to 0b00.

.. _rbits-SFP:

SFP[5:0] (sramF_pulse)
----------------------------

Timing Control Filter SRAM - CLK Pulse.

.. _rbits-FCKE:

FCKE (filter_clk_en)
----------------------------

Filter clock enable. If '1', the *CLK_SLOW* signal
is used as filter clock.

.. note:: The *CLK_SLOW* is forwarded to the filter only when register bits
   :ref:`SLWCLK[7:0]<rbits-SLWCLK>` are configured accordingly.

.. _rbits-FBYP:

FBYP (filter_bypass)
----------------------------

When '1' (default), the filter is bypassed.
When '0', the DVS events are filtered.

.. _rbits-SFT:

SFT[5:0] (sramF_setup)
----------------------------

Timing Control Filter SRAM - CLK Setup.

.. _rbits-FDEL:

FDEL[15:0] (filter_delta)
----------------------------

Defines the threshold of the filter. See :ref:`dvs-filter`.

.. _rbits-FMOE:

FMOE (filter_mon_en)
----------------------------

Enables monitoring of the filter internal messages before counter delta comparison (for debug purposes).

.. _rbits-FKSY:

FKSY[2:0] (filter_size_y)
----------------------------

Filter size in the Y dimension.

.. _rbits-FKSX:

FKSX[2:0] (filter_size_x)
----------------------------

Filter size in the X dimension.

.. _rbits-HPFE:

HPFE (hot_pixel_filter_en)
---------------------------

Enables the filter when set to '1'.

.. _rbits-FLPF:

FLPF (filter_lpf)
-----------------

Filter low-pass mode enable bit. See :ref:`_filter-low-pass-mode`.

.. _rbits-FMDST:

FMDST[3:0] (filter_mon_dest)
----------------------------

Filter monitor destination tag. When FMOE is enabled,
the FMDST is appended to the output message on the monitor bus.

The FMDST should be set to the default value 0b1010 in order
to match the table shown in :ref:`monitor-encoding-table`.

.. _rbits-SFBT:

SFBT[1:0] (sramF_bist_tsel)
---------------------------

BIST mode Filter SRAM Read Timing Control.

.. note:: The internal BIST Filter SRAM Read timing value is calculated as {SFBT1, !(SFBT0)}.
    Therefore, to obtain an internal setting of 0b01, the register SFBT must be set to 0b00.
