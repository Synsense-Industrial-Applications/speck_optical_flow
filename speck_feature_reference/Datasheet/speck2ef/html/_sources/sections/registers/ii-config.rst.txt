Detailed Signal Description
***************************


.. _rbits-PR:

PR (PRst)
---------

Location: :ref:`ININT0[7]<reg-ININT0>`

Main Logic PRst. This signal is forwarded to the internal logic only when :ref:`CGUIS<rbits-CGUIS>` = '0'.


.. _rbits-SR:

SR (SRst)
---------

Location: :ref:`ININT0[6]<reg-ININT0>`

Main Logic SRst. This signal is forwarded to the internal logic only when :ref:`CGUIS<rbits-CGUIS>` = '0'.


.. _rbits-PRDVS:

PRDVS (PRst_DVS)
----------------

Location: :ref:`ININT0[5]<reg-ININT0>`

Internal DVS PRst. This signal is forwarded to the internal logic only when :ref:`CGUIS<rbits-CGUIS>` = '0'.


.. _rbits-SRDVS:

SRDVS (SRst_DVS)
----------------

Location: :ref:`ININT0[4]<reg-ININT0>`

Internal DVS SRst. This signal is forwarded to the internal logic only when :ref:`CGUIS<rbits-CGUIS>` = '0'.


.. _rbits-CGUCE:

CGUCE (cgu_clk_enable)
----------------------

Location: :ref:`ININT0[2]<reg-ININT0>`

Force spi master and slave clk enable.


.. _rbits-CGUIS:

CGUIS (cgu_ii_sel)
------------------

Location: :ref:`ININT0[1]<reg-ININT0>`

Select origin of Reset signals (PRst, SRst, PRst_DVS, SRst_DVS):

+---------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| Setting | Description                                                                                                                                                             |
+---------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| '0'     | Internal reset signals are set by the corresponding register settings (:ref:`PR<rbits-PR>`, :ref:`SR<rbits-SR>`, :ref:`PRDVS<rbits-PRDVS>`, :ref:`SRDVS<rbits-SRDVS>`). |
+---------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| '1'     | Internal reset signals are set by the :ref:`Input Serial Interface<input-serial-interface-encoding>` (see :ref:`ISI Reset Signals<isi-resets>`).                        |
+---------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------+



.. _rbits-CGUOVE:

CGUOVE (cgu_overwrite_ext_mem_ok)
---------------------------------

Location: :ref:`ININT0[0]<reg-ININT0>`

Enable chip config from SPI slave after external Flash loaded. '0' (default) = disabled.

BLEN[23:0] (burst_len)
----------------------

Location: :ref:`ININT1[7:0]<reg-ININT1>`, :ref:`2[7:0]<reg-ININT2>`, :ref:`3[7:0]<reg-ININT3>`

SPI Slave input burst length.


.. _rbits-BADDR:

BADDR[23:0] (burst_addr)
------------------------

Location: :ref:`ININT4[7:0]<reg-ININT4>`, :ref:`5[7:0]<reg-ININT5>`, :ref:`6[7:0]<reg-ININT6>`

SPI Slave input burst starting target address.


.. _rbits-IOSEL:

IOSEL[6:0] (iosel)
------------------

Location: :ref:`ININT7[6:0]<reg-ININT7>`

I/O ring configuration selector. See section :ref:`gpio-configuration` for the configuration details.

.. _rbits-P2SSEL:

P2SSEL (p2s_input_sel)
----------------------

Location: :ref:`ININT8[2]<reg-ININT8>`

Output P2S input selector ('0': monitor bus, '1': readout layer output).

.. _rbits-P2S2CH:

P2S2CH (p2s_two_ch_sel)
-----------------------

Location: :ref:`ININT8[1]<reg-ININT8>`

Output P2S dual channel: '0': disabled, '1': enabled.

.. _rbits-P2SDL:

P2SDL (p2s_data_len)
--------------------

Location: :ref:`ININT8[0]<reg-ININT8>`

Output P2S data word length selector. When '0': a full data word of 26 bits is clocked at the `OUT1` (and `OUT2`, when enabled).
When '1': only the LSB 17 bits are sent to the output (for faster throughput, when the MSBs are obvious by configuration).

Input Interface Monitor enable.

P2SM (p2s_mon_en)
-----------------

Location: :ref:`ININT8[5]<reg-ININT8>`

General monitor bus enable via P2S output interface..

.. _rbits-JTGM:

JTGM (jtag_mon_en)
------------------

Location: :ref:`ININT8[4]<reg-ININT8>`

Enable forwarding of monitor bus to JTAG interface..


.. _rbits-SPIBRG:

SPIBRG (iospi_bridge_modepe)
----------------------------

Location: :ref:`ININT9[6]<reg-ININT9>`

SPI Bridge mode enable bit. When enabled, the SPI Slave interface of the chip is directly connected to the
SPI Master interface. This mode enables direct Write or Read of an SPI external Flash memory connected to the
SPI Master interface of the chip. When enabled, the SPI Slave interface pins do not control any more the internal
memory interfaces of the chip, i.e. SPI cannot be used any more to read/write SRAMs and registers.

.. _rbits-IOPE:

IOPE[5:0] (iope)
----------------

Location: :ref:`ININT9[5:0]<reg-ININT9>`

I/O ring pull-down enable bits.
The pull-down settings are summarized in the following table. When an IOPE bit is set, the pull-down resistors are enabled
for the corresponding chip pins:

+----------+---------------+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| IOPE bit | Pin group     | Pull-down enabled for pins                                                                                                                                                                     |
+----------+---------------+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| 0        | Mode sel      | IO26_MODE_SEL_I                                                                                                                                                                                |
+----------+---------------+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| 1        | S2P           | IO15_S2P_DREADY_I, IO16_S2P_DATA_I                                                                                                                                                             |
+----------+---------------+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| 2        | GPIO 11-14    | GPIO12_SPI_S_MOSI_IO, GPIO13_SPI_S_CLK_IO, GPIO14_SPI_S_SS_N_IO                                                                                                                                |
+----------+---------------+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| 3        | GPIO 7-10     | GPIO7_SPI_M_MISO_IO, GPIO8_SPI_M_MOSI_IO, GPIO9_SPI_M_CLK_IO, GPIO10_SPI_M_SS_N_IO                                                                                                             |
+----------+---------------+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| 4        | Fixed inputs  | IO1_CLK_I, I02_RB_I, IO3_TCK_I, IO4_TDI_I, IO5_TMS_I                                                                                                                                           |
+----------+---------------+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| 5        | RGB Interface | IO40_RGB_PCLK_I, IO29_RGB_HREF_I, IO28_RGB_VSYNC_I, IO31_RGB_INT_CLK_I, IO32_RGB_D2_I, IO33_RGB_D3_I, IO34_RGB_D4_I, IO35_RGB_D5_I, IO36_RGB_D6_I, IO37_RGB_D7_I, IO38_RGB_D8_I, IO39_RGB_D9_I |
+----------+---------------+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

.. note:: In the case of GPIO pins, the pull-down resistors are active only when the pin is set to *Input*.

.. _rbits-SLWCLK:

SLWCLK[7:0] (slow_clock)
------------------------

Location: :ref:`ININT10[7:0]<reg-ININT10>`

Configuration register for the *SLOW_CLK* pin. For a description of the slow clock use and generation
in Speck2e, see :ref:`slow-clock`.

+-------------+---------------------------------------------------------------------------------+
| Bit         | Description                                                                     |
+-------------+---------------------------------------------------------------------------------+
| SLWCLK[0]   | Forward *SLOW_CLK* to readout block                                             |
+-------------+---------------------------------------------------------------------------------+
| SLWCLK[1]   | Forward internally generated slow clock to readout block                        |
+-------------+---------------------------------------------------------------------------------+
| SLWCLK[2]   | Forward *SLOW_CLK* to convolutional layers' leak generator                      |
+-------------+---------------------------------------------------------------------------------+
| SLWCLK[3]   | Forward internally generated slow clock to convolutional layers' leak generator |
+-------------+---------------------------------------------------------------------------------+
| SLWCLK[4]   | Forward *SLOW_CLK* to DVS filter                                                |
+-------------+---------------------------------------------------------------------------------+
| SLWCLK[5]   | Forward internally generated slow clock to DVS filter                           |
+-------------+---------------------------------------------------------------------------------+
| SLWCLK[6:7] | Configure clk divider for internal slow clock generation                        |
+-------------+---------------------------------------------------------------------------------+

Internal slow clock divider configuration (SLWCLK[6:7]):

+---------------+-----------------+
| Configuration | Description     |
+---------------+-----------------+
| 00            | 14-bit division |
+---------------+-----------------+
| 01            | 15-bit division |
+---------------+-----------------+
| 10            | 16-bit division |
+---------------+-----------------+
| 11            | 17-bit division |
+---------------+-----------------+
