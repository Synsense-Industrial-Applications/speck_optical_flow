.. _sizing-constraints:

Layer Sizing Constraints
========================

Due to SRAM sizing, every layer must be configured to comply with sizing rules for its 
kernel size and shape of the neuron layer.

In the following, the memory constraints for the different layers are outlined, 
and some examples are provided for correct sizing of input/output feature numbers and kernel size.

Neuron Memory Constraints
-------------------------

For a given Input Feature numbers (X and Y), the following table summarizes the maximum number of output features.

The table is divided into two parts, showing the possible configurations in the cases:

- X/Y aspect ratio >50%, where X=Y, X/Y=2 or Y/X=2
- X/Y aspect ratio <50% and >25%, where X/Y=4 or Y/X=4

Network Sizing
--------------

Let a network be defined by the number of input features :math:`c`, the number of output features :math:`f`,
and the kernel dimensions :math:`k_x`, and :math:`k_y`.

The theoretical number of entries required for kernel memory :math:`K_M` is then

.. math::

   K_M = c f k_x k_y

The actual number of entries required in chip memory because of the address encoding scheme described in the following section.
The total number of memory entries required is

.. math::

   K_{MT} = c \cdot 2^{\lceil \log_2\left(k_xk_y\right) \rceil + \lceil \log_2\left(f\right) \rceil}

The required number of neuron memory entries :math:`N_M` depends on the dimensions of the input features :math:`c_x`, and :math:`c_y`,
as well as the stride and padding :math:`s_x, s_y`, and :math:`p_x, p_y`.

.. math::

   f_x &= \frac{c_x - k_x + 2 p_x}{s_x} + 1 \\
   f_y &= \frac{c_y - k_y + 2 p_y}{s_y} + 1 \\
   N_M &= f f_x f_y

Again the total number of required entries on the chip side is larger.

.. math::

   N_{MT} = f \cdot 2^{ \lceil \log_2\left(f_y\right) \rceil + \lceil \log_2\left(f_x\right) \rceil }
