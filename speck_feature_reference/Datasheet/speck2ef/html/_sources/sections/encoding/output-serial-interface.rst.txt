.. _output-serial-interface-encoding:

Output Serial Interface Encoding
================================

As described in the :ref:`output-serial-interface` section, the output interface receives
data from both the Monitor bus (*data1*, channel #1) and the Output MUX (*data2*, channel #2).

Source 1 (Monitor bus)
-----------------------

The encoding of the Monitor bus can be found in section: :ref:`monitor-bus-encoding`.

.. _readout-to-p2s-encoding:

Source 2 (Readout Layer)
-------------------------

When Source 2 is selected to be sent to the output serial interface, output serializer
outputs the state of the :ref:`Readout Layer<readout-layer>`
For the encoding in normal operation, see :ref:`readout-output-modes`.
