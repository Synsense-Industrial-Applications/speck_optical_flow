SPI Master
==========

The following SPI master modes are supported:

- External to Internal (E2I): SPI master fetches data from external FLASH memory and writes to internal registers / SRAMs
- SPI Mode 0: CPOL = 0, CPHA = 0

.. _spi-master-port:

Port
****

+--------------+------+---------------------------------------------+------------+
| Port Name    | Bits | Description                                 | Remark     |
+--------------+------+---------------------------------------------+------------+
| spi_m_clk_i  | 1    | outgoing SPI clock                          |            |
+--------------+------+---------------------------------------------+------------+
| spi_m_ss_n_i | 1    | slave select                                | low active |
+--------------+------+---------------------------------------------+------------+
| spi_m_mosi_i | 1    | outgoing data from master to external FLASH |            |
+--------------+------+---------------------------------------------+------------+
| spi_m_miso_o | 1    | incoming data to master from external FLASH |            |
+--------------+------+---------------------------------------------+------------+

E2I Mode
********

In this mode SPI master fetches data from external FLASH, then writes to internal register / SRAMs.

Flash consists of blocks, sectors and pages.

* each block consists of 16 sectors, in total 64 KB
* each sector consists of 16 pages, in total 4 KB
* each page consists of 256 bytes

Address calculation
-------------------

+--------------+----------------+-----------------+---------------+---------------+
| Address bits | 23:16          | 15:12           | 11:8          | 7:0           |
+--------------+----------------+-----------------+---------------+---------------+
| Part         | Block (8 bits) | Sector (4 bits) | Page (4 bits) | Byte (8 bits) |
+--------------+----------------+-----------------+---------------+---------------+

Example
-------

For example 4 Mbit FLASH consists of 8 blocks, 8 Mbit FLASH consists of 16 blocks.

SPI Interface Registers
***********************

These SPI interface registers are read from the external FLASH memory, and are used to configure the memory structure *on the fly*.

Lx_KMS
------

Note: x = {0, 1, 2, 3, 4, 5, 6, 7, 8}

+----------+-------+-------+----------------------------+--------------------------------------------------------------------------------+---------------+
| Position | Width | Field | Name                       | Description                                                                    | Default Value |
+----------+-------+-------+----------------------------+--------------------------------------------------------------------------------+---------------+
| 7        | 1     | rsvd  | reserved                   | reserved for future use                                                        | 1             |
+----------+-------+-------+----------------------------+--------------------------------------------------------------------------------+---------------+
| 6:4      | 3     | LxBA  | Layerx_Kernel_Block_Addr   | Layer x Kernel Block Location                                                  | 0             |
+----------+-------+-------+----------------------------+--------------------------------------------------------------------------------+---------------+
| 3:2      | 2     | LxSS  | Layerx_Kernel_Start_Sector | higher 2 bits of start sector for Layer x Kernel Memory, lower 2 bits are "00" | 2             |
+----------+-------+-------+----------------------------+--------------------------------------------------------------------------------+---------------+
| 1:0      | 2     | LxES  | Layerx_Kernel_End_Sector   | higher 2 bits of end sector for Layer x Kernel Memory, lower 2 bits are "11"   | 3             |
+----------+-------+-------+----------------------------+--------------------------------------------------------------------------------+---------------+

Lx_LMS
------

Note: x = {0, 1, 2, 3, 4, 5, 6, 7, 8}

+----------+-------+-------+----------------------------+-----------------------------------+---------------+
| Position | Width | Field | Name                       | Description                       | Default Value |
+----------+-------+-------+----------------------------+-----------------------------------+---------------+
| 7:5      | 3     | LxBA  | Layerx_Leak_Block_Addr     | Layer x Leak block Location       | 0             |
+----------+-------+-------+----------------------------+-----------------------------------+---------------+
| 4:1      | 4     | LxSA  | Layerx_Leak_Sector_Addr    | Layer x Leak sector Location      | 4             |
+----------+-------+-------+----------------------------+-----------------------------------+---------------+
| 0        | 1     | LxSS  | Layerx_Leak_Sector_Section | 0: first 8 pages, 1: last 8 pages | 3             |
+----------+-------+-------+----------------------------+-----------------------------------+---------------+
