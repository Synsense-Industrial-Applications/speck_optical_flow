7.4.1. Detailed Signal Description

7.4.1.1. PR (PRst)

Location: ININT0[7]

Main Logic PRst. This signal is forwarded to the internal logic only when CGUIS = ‘0’.

7.4.1.2. SR (SRst)

Location: ININT0[6]

Main Logic SRst. This signal is forwarded to the internal logic only when CGUIS = ‘0’.

7.4.1.3. PRDVS (PRst_DVS)

Location: ININT0[5]

Internal DVS PRst. This signal is forwarded to the internal logic only when CGUIS = ‘0’.

7.4.1.4. SRDVS (SRst_DVS)

Location: ININT0[4]

Internal DVS SRst. This signal is forwarded to the internal logic only when CGUIS = ‘0’.

7.4.1.5. CGUCE (cgu_clk_enable)

Location: ININT0[2]

Force spi master and slave clk enable.

7.4.1.6. CGUIS (cgu_ii_sel)

Location: ININT0[1]

Select origin of Reset signals (PRst, SRst, PRst_DVS, SRst_DVS):

Setting

Description

‘0’

Internal reset signals are set by the corresponding register settings (PR, SR, PRDVS, SRDVS).

‘1’

Internal reset signals are set by the Input Serial Interface (see ISI Reset Signals).

7.4.1.7. CGUOVE (cgu_overwrite_ext_mem_ok)

Location: ININT0[0]

Enable chip config from SPI slave after external Flash loaded. ‘0’ (default) = disabled.

7.4.1.8. BLEN[23:0] (burst_len)

Location: ININT1[7:0], 2[7:0], 3[7:0]

SPI Slave input burst length.

7.4.1.9. BADDR[23:0] (burst_addr)

Location: ININT4[7:0], 5[7:0], 6[7:0]

SPI Slave input burst starting target address.

7.4.1.10. IOSEL[6:0] (iosel)

Location: ININT7[6:0]

I/O ring configuration selector. See section GPIO Pin Configuration for the configuration details.

7.4.1.11. P2SSEL (p2s_input_sel)

Location: ININT8[2]

Output P2S input selector (‘0’: monitor bus, ‘1’: readout layer output).

7.4.1.12. P2S2CH (p2s_two_ch_sel)

Location: ININT8[1]

Output P2S dual channel: ‘0’: disabled, ‘1’: enabled.

7.4.1.13. P2SDL (p2s_data_len)

Location: ININT8[0]

Output P2S data word length selector. When ‘0’: a full data word of 26 bits is clocked at the OUT1 (and OUT2, when enabled). When ‘1’: only the LSB 17 bits are sent to the output (for faster throughput, when the MSBs are obvious by configuration).

7.4.1.14. AERCM (aerc_mon_en)

Location: ININT8[6]

Input Interface Monitor enable.

7.4.1.15. P2SM (p2s_mon_en)

Location: ININT8[5]

General monitor bus enable via P2S output interface..

7.4.1.16. JTGM (jtag_mon_en)

Location: ININT8[4]

Enable forwarding of monitor bus to JTAG interface..

7.4.1.17. SPIBRG (iospi_bridge_modepe)

Location: ININT9[6]

SPI Bridge mode enable bit. When enabled, the SPI Slave interface of the chip is directly connected to the SPI Master interface. This mode enables direct Write or Read of an SPI external Flash memory connected to the SPI Master interface of the chip. When enabled, the SPI Slave interface pins do not control any more the internal memory interfaces of the chip, i.e. SPI cannot be used any more to read/write SRAMs and registers.
