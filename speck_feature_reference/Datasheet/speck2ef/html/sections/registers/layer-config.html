7.6.1. Detailed Signal Description

7.6.1.1. BEN (balancer_en)

Spike input rate balancer enable bit. When enabled, any spike received by the layer while the layer input pipeline is busy is discarded. As soon as the layer input is able to accept another input spike, the coming spike is forwarded.

7.6.1.2. DEN (decimator_en)

Spike output decimator enable bit. When enabled, only a fraction of the spikes generated in the layer is forwarded to the layer output. The fraction of forwarded spikes can be configured via the register bits DINT

7.6.1.3. DINT (decimator_interval)

Configures the fraction of forwarded spikes at the output of the layer when the DEN bit is enabled. See Spike Decimator Block for more information.

7.6.1.4. SCX[1:0] (Stride_CaseX)

Stride in X direction. Maps to {1,2,4,8}

7.6.1.5. ZPY[2:0] (zeropaddingY)

Zero padding applies to start and end of input in Y direction.

7.6.1.6. ZPX[2:0] (zeropaddingX)

Zero padding applies to start and end of input in X direction.

7.6.1.7. KSZ[3:0] (ksize)

Size of kernels in layer. The kernel size X*Y will be (N+1)*(N+1) for a programmed value N.

7.6.1.8. SCY[1:0] (Stride_CaseY)

Stride in Y direction. Maps to {1,2,4,8}

7.6.1.9. IFN[9:0] (in_fnum)

Number of input features to layer. The number of input features of a layer A must be equal with the sum of output features of all layers that are inputs to layer A. To parition where the features of a layer B that outputs to layer A are mapped in the inputs of layer A user must use shift feature number. This number will move the n output features of layer B in [<shift feature number>,<shift feature number> + n] space. If two or more output feature spaces from different layers overimpose the destination layer can-t make a difference between them. The input feature X and Y of a layer A has to be equal with output feature X and Y respectively of all layers that are inputs to layer A.

7.6.1.10. OFSX[5:0] (out_fsizeX)

Size of output feature maps in X dimension. Calculated as fsize_out_X=[(fsize_in_Y-Filter_size+2*Zero_padding_X)/Stride_X]+1.

7.6.1.11. OFN[9:0] (out_fnum)

Number of output features to produce. Programmed value is N-1 for a number of features N.

7.6.1.12. OFSY[5:0] (out_fsizeY)

Size of output feature maps in Y dimension. Calculated as fsize_out_Y=[(fsize_in_Y-Filter_size+2*Zero_padding_Y)/Stride_Y]+1.

7.6.1.13. SKP[5:0] (sramK_pulse)

Timing Control Kernel SRAM - CLK Pulse. The default timing is ‘010000’, the dly ctl is linear for bit 0-4 with a binary step size of 200ps offset of 275ps, bit 5 adds a security delay of 6 ns on top.

7.6.1.14. SKR[1:0] (sramK_read)

Timing Control Kernel SRAM - Read Data Ready.

Note

The internal Kernel SRAM Read timing value is calculated as {SKR1, !(SKR0)}. Therefore, to obtain an internal setting of 0b01, the register SKR must be set to 0b00.

7.6.1.15. SKT[5:0] (sramK_setup)

Timing Control Kernel SRAM - CLK setup. The default timing is ‘010000’, the dly ctl is linear for bit 0-4 with a binary step size of 200ps, offset of 275ps, bit 5 adds a security delay of 6 ns on top.

7.6.1.16. LKEN (leak_en)

Boolean value for enabling membrane potential leakage. 1 for true, 0 for false.

7.6.1.17. SLT[5:0] (sramL_setup)

Timing Control Leak SRAM - CLK setup. The default timing is ‘010000’, the dly ctl is linear for bit 0-4 with a binary step size of 100ps, offset of 275ps, bit 5 adds a security delay of 3.6 ns on top

7.6.1.18. SLP[5:0] (sramL_pulse)

Timing Control Leak SRAM - CLK Pulse. The default timing is ‘010000’, the dly ctl is linear for bit 0-4 with a binary step size of 200ps offset of 275ps, bit 5 adds a security delay of 6 ns on top

7.6.1.19. SLR[1:0] (sramL_read)

Timing Control Leak SRAM - Read Data Ready.

Note

The internal Leak SRAM Read timing value is calculated as {SLR1, !(SLR0)}. Therefore, to obtain an internal setting of 0b01, the register SLR must be set to 0b00.

7.6.1.20. THRH[15:0] (neuron_thr_hi)

Neuron Upper Threshold: Programmed value of neuron firing threshold. 2K encoding - programm the threshold value x(-1) (invert).

7.6.1.21. THRL[15:0] (neuron_thr_lo)

Neuron Lower Threshold: The minimum value of the neuron membrane potential which cannot be surpassed by leak. 2K encoding - programm the threshold value x(-1) (invert).

7.6.1.22. SNT[5:0] (sramN_setup)

Neuron SRAM setup timing. The default timing is ‘010000’, the dly ctl is linear for bit 0-4 with a binary step size of 100ps, offset of 275ps, bit 5 adds a security delay of 3.6 ns on top.

7.6.1.23. NRZ (neuron_rtz_en)

Neuron return to Zero. Return to zero, 1 if true, 0 if false. If false, the neuron membrane potential will be set to (membrane potential - high threshold) when fired.

7.6.1.24. SNP[5:0] (sramN_pulse)

Neuron SRAM pulse timing. The default timing is ‘010000’, the dly ctl is linear for bit 0-4 with a binary step size of 200ps, offset of 275ps, bit 5 adds a security delay of 6 ns on top.

7.6.1.25. SNR[1:0] (sramN_read)

Timing Control Neuron SRAM - Read Data Ready.

Note

The internal Neuron SRAM Read timing value is calculated as {SNR1, !(SNR0)}. Therefore, to obtain an internal setting of 0b01, the register SNR must be set to 0b00.

7.6.1.26. SNBT[1:0] (sramN_bist_tsel)

BIST mode Neuron SRAM Read Timing Control.

Note

The internal BIST Neuron SRAM Read timing value is calculated as {SNBT1, !(SNBT0)}. Therefore, to obtain an internal setting of 0b01, the register SNBT must be set to 0b00.

7.6.1.27. SKBT[1:0] (sramK_bist_tsel)

BIST mode Kernel SRAM Read Timing Control.

Note

The internal BIST Kernel SRAM Read timing value is calculated as {SKBT1, !(SKBT0)}. Therefore, to obtain an internal setting of 0b01, the register SKBT must be set to 0b00.

7.6.1.28. SLBT[1:0] (sramL_bist_tsel)

BIST mode Leak SRAM Read Timing Control.

Note

The internal BIST Leak SRAM Read timing value is calculated as {SLBT1, !(SLBT0)}. Therefore, to obtain an internal setting of 0b01, the register SLBT must be set to 0b00.
