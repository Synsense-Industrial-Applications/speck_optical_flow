7.12.1. Detailed Signal Description

7.12.1.1. SFR[1:0] (sramF_read)

Timing Control Filter SRAM - Read Data Ready.

Note

The internal Filter SRAM Read timing value is calculated as {SFR1, !(SFR0)}. Therefore, to obtain an internal setting of 0b01, the register SFR must be set to 0b00.

7.12.1.2. SFP[5:0] (sramF_pulse)

Timing Control Filter SRAM - CLK Pulse.

7.12.1.3. FCKE (filter_clk_en)

Filter clock enable. If ‘1’, the CLK_SLOW signal is used as filter clock.

Note

The CLK_SLOW is forwarded to the filter only when register bits SLWCLK[7:0] are configured accordingly.

7.12.1.4. FBYP (filter_bypass)

When ‘1’ (default), the filter is bypassed. When ‘0’, the DVS events are filtered.

7.12.1.5. SFT[5:0] (sramF_setup)

Timing Control Filter SRAM - CLK Setup.

7.12.1.6. FDEL[15:0] (filter_delta)

Defines the threshold of the filter. See DVS Event Filter.

7.12.1.7. FMOE (filter_mon_en)

Enables monitoring of the filter internal messages before counter delta comparison (for debug purposes).

7.12.1.8. FKSY[2:0] (filter_size_y)

Filter size in the Y dimension.

7.12.1.9. FKSX[2:0] (filter_size_x)

Filter size in the X dimension.

7.12.1.10. HPFE (hot_pixel_filter_en)

Enables the filter when set to ‘1’.

7.12.1.11. FLPF (filter_lpf)

Filter low-pass mode enable bit. See _filter-low-pass-mode.

7.12.1.12. FMDST[3:0] (filter_mon_dest)

Filter monitor destination tag. When FMOE is enabled, the FMDST is appended to the output message on the monitor bus.

The FMDST should be set to the default value 0b1010 in order to match the table shown in Speck2e Monitor Bus Encoding.

7.12.1.13. SFBT[1:0] (sramF_bist_tsel)

BIST mode Filter SRAM Read Timing Control.

Note

The internal BIST Filter SRAM Read timing value is calculated as {SFBT1, !(SFBT0)}. Therefore, to obtain an internal setting of 0b01, the register SFBT must be set to 0b00.
