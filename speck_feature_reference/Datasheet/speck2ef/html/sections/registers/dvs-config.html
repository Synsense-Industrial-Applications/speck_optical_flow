7.10.1. Detailed Signal Description

7.10.1.1. DMOEN (DVS_Mon)

Enables the DVS Monitor Bus. When enabled, input messages to the dvs pre-processing block are forwarded on the monitor bus to the output serial interface data1 input.

Note

These messages are the raw messages coming from the internal DVS or an external sensor (Ext DVS Mode) before pre-processing.

7.10.1.2. SMOEN (Spike_Mon)

Enables the DVS Pre-Processing Spike Monitor Bus. When enabled, output messages of the dvs pre-processing block are forwarded on the monitor bus to the output serial interface data1 input.

7.10.1.3. DSD2EN (Spike_Dst2)

Enable forwarding to Destination 2 layer (address defined in bits DSD2[4:0] (Spike_Dst2).

7.10.1.4. DSD1EN (Spike_Dst1)

Enable forwarding to Destination 1 layer (address defined in bits DSD1[4:0] (Spike_Dst1).

7.10.1.5. DMI (diagonal_mirror_en)

Enables mirroring of the input events along the diagonal: when set to ‘1’, it swaps X with Y.

7.10.1.6. IM[2:0] (image_mode)

Location: DVS0[2:0]

DVS event filtering. Filters/merges events coming from the DVS Bus (Sensor or External).

IM[2:0]

Configuration

000

Pass Events with both polarity (to ON and to OFF). Merge all events marking them with Polarity = ‘1’.

001

Pass only Events with OFF polarity. Mark all events with Polarity ‘1’.

010

Pass only Events with ON polarity. Mark all events with Polarity ‘1’.

011

Block all events.

1xx

Pass all events and maintain the polarity information.

7.10.1.7. COX[6:0] (cut_origin_x)

ROI Min X coordinate, calculated from the image origin.

7.10.1.8. SSX[1:0] (subsamp_x)

Select the level of Pooling in the X dimension. Values {0, 1, 2} map to a Pooling of {1, 2, 4}.

7.10.1.9. COY[6:0] (cut_origin_y)

ROI Min Y coordinate, calculated from the image origin.

7.10.1.10. SSY[1:0] (subsamp_y)

Select the level of Pooling in the Y dimension. Values {0, 1, 2} map to a Pooling of {1, 2, 4}.

7.10.1.11. CMX[6:0] (cut_max_x)

ROI Max X coordinate, calculated from the image origin.

7.10.1.12. XME (x_mirror_en)

Enable mirroring of the X dimension.

7.10.1.13. CMY[6:0] (cut_max_y)

ROI Max Y coordinate, calculated from the image origin.

7.10.1.14. YME (y_mirror_en)

Enable mirroring of the Y dimension.

7.10.1.15. DSD2[4:0] (Spike_Dst2)

Destination 2 layer address.

7.10.1.16. DSD1[4:0] (Spike_Dst1)

Destination 1 layer address.

7.10.1.17. SDL[7:0] (sensor_dly)

Sensor configuration valid -> ack delay control. This register controls the timing of the ack signal for a sensor configuration event coming from the Input Serial Interface (see ISI Operating Modes)

7.10.1.23. SPSS (sensor_pass)

Pass/Drop Internal DVS Events. If disabled, the internal sensor events are dropped, i.e., not forwarded to the DVS pre-processing block.

This is typically used when sensor data is provided by an external source (Ext DVS Mode).

SPSS

Configuration

‘0’

Drop internal DVS events

‘1’

Forward internal DVS events to DVS pre-processing block
