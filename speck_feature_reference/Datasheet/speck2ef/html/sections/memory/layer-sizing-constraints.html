8.2. Layer Sizing Constraints

Due to SRAM sizing, every layer must be configured to comply with sizing rules for its kernel size and shape of the neuron layer.

In the following, the memory constraints for the different layers are outlined, and some examples are provided for correct sizing of input/output feature numbers and kernel size.

8.2.3. Network Sizing

Let a network be defined by the number of input features \(c\), the number of output features \(f\), and the kernel dimensions \(k_x\), and \(k_y\).

The theoretical number of entries required for kernel memory \(K_M\) is then

\[K_M = c f k_x k_y\]

The actual number of entries required in chip memory because of the address encoding scheme described in the following section. The total number of memory entries required is

\[K_{MT} = c \cdot 2^{\lceil \log_2\left(k_xk_y\right) \rceil + \lceil \log_2\left(f\right) \rceil}\]

The required number of neuron memory entries \(N_M\) depends on the dimensions of the input features \(c_x\), and \(c_y\), as well as the stride and padding \(s_x, s_y\), and \(p_x, p_y\).

\[\begin{split}f_x &= \frac{c_x - k_x + 2 p_x}{s_x} + 1 \\ f_y &= \frac{c_y - k_y + 2 p_y}{s_y} + 1 \\ N_M &= f f_x f_y\end{split}\]

Again the total number of required entries on the chip side is larger.

\[N_{MT} = f \cdot 2^{ \lceil \log_2\left(f_y\right) \rceil + \lceil \log_2\left(f_x\right) \rceil }\]
