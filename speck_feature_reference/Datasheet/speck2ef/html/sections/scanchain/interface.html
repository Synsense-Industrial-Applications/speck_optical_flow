13.5. Scan Chain Interface

As described in Scan Chain Overview, the Speck2e Scan Chain (SC) interface includes internal signals:

Signal

Description

External pin

SCAN_HS_EN

Scan chain control (handshake) enable

—

SCAN_DATA_EN

Scan chain data enable

—

SCAN_CLK

Scan chain control and data clock

TCK

SCAN_IN

Scan chain control and data in

TDI + FF

SCAN_OUT

Scan chain control and data out

TDO

Warning

The IO4_TDI pin is connected to the internal SCAN_IN signal via a Filp-Flop to force sampling of the data at IO4_TDI always on the rising edge. Please refer to section below Scan Chain Interface Timing (for IC design use only) for the correct timing of the TDI/TDO data.

13.5.1. Scan Chain Domain Enable

In order to operate the scan chain, a SC sub-domain has to be activated first. This is done through a register setting. Refer to section Scan Chain Domains for a list of registers associated to each sub-domain.

Warning

Only a single SC sub-domain can be activated at each moment, otherwise the SC bit stream will be injected to all active sub-domains, creating a conflict and invalid output data.

13.5.2. Scan Chain Interface Timing (for IC design use only)

After setting the SC enable bit for the selected sub-domain, the SC interface can be activated by setting pin SCAN_HS_EN to ‘1’ and subsequently SCAN_DATA_EN to ‘1’. | In Speck2e this is done via JTAG commands (see JTAG Command Reference).

At this point, the SC of the sub-domain is ready to accept and output a bit stream.

Both input and output data is sampled at the internal SCAN_CLK falling edge. When clocking the data in via JTAG, the data is sent/read via TDI/TDO pins at which the data is sampled at the rising edge of JTAG_CLK.

Warning

In order to guarantee compatibility with the standard JTAG protocol, every bitstream should start with an extra ‘0’ bit and the first output bit sampled on TDO should be ignored. For example, for a scan chain length of 5101 bits, the user should clock in 5102 bits of which the first is a ‘0’ and the first bit received on TDO is ignored.

The following diagram shows the SC operation for a sample bit stream of 10 bits, where bit #9 is the MSB and bit #0 is the LSB of the bitstring. The input bit string will displace the internal bit string (of the same length), so that the first output bit on SCAN_OUT will correspond to the first bit sent at the input (O#0).

Warning

For IC Design use only: not relevant to design external chip interfaces.

After the end of the bit stream clocking, the SC can be deactivated to resume chip operation (see MODE 1: Normal Async Operation). In this case, SCAN_DATA_EN must be set to ‘0’ before SCAN_HS_EN. A delay >10 ns should be introduced in between disabling HS and DATA SC enable signals to allow for control signals to propagate and stabilize.
