Note

  1. GPIO7 to GPIO10 pins are used for SPI Master pins always during the power-up. After download is finished, these pins are configured via the register setting in IOSEL[6:5] bits.

  2. GPIO11 to GPIO14 pins state during power-up is defined by ModeSel pin state. If it is connected to “high”, these pins are powered up as READOUT signals otherwise they can be used for SPI slave pins

  3. The states of GPIO11 to GPIO14 after download from external memory is complete is defined by IOSEL[4:3] register setting”
