11.4. JTAG Register Access

The JTAG interface can be used to read/write all registers of Speck2e.

11.4.1. Register Write Operation

A register can be read/written by first sending a SET_ADDR command, followed by streaming in 24 bits to the internal ADDR register of the JTAG interface in the following format:

ADDR_REGISTER [23:0] breakdown:

Part

Bits

Unused (all ‘0’)

[23:10]

Register Block ID

[9:6]

Register Local Address

[5:0]

Register block selection table:

Register Block ID

Selected Register Block

0b0000

ININT0-10

0b0001

DVS0-15, FILTER0-5

0b0010

READOUT0-15

0b0011

Layer 0 CONV0-21

0b0100

Layer 1 CONV0-21

0b0101

Layer 2 CONV0-21

0b0110

Layer 3 CONV0-21

0b0111

Layer 4 CONV0-21

After loading the ADDR register, a stream of consequent data elements can be written in, after sending the REGISTER_WRITE command:

send_ir(SET_ADDR, 0x10, 8 bits)
send_dr(ADDR_REGISTER, 24 bits)
send_ir(REGISTER_WRITE, 0x12, 8 bits)
send_dr(data[7:0], 8 bits)  # Addr
send_dr(data[7:0], 8 bits)  # Addr + 1
...
send_dr(data[7:0], 8 bits)  # Addr + n

11.4.2. Register Read Operation

A register read is equivalent to a Register Write operation, whereas the selected command is REGISTER_READ:

send_ir(SET_ADDR, 0x10, 8 bits)
send_dr(ADDR_REGISTER, 24 bits)
send_ir(REGISTER_READ, 0x11, 8 bits)
send_dr(0b0000_0000, 8 bits)  # Read out register @Addr on TDO
send_dr(0b0000_0000, 8 bits)  # Read out register @(Addr + 1) on TDO
...
send_dr(0b0000_0000, 8 bits)  # Read out register @(Addr + 2) on TDO
