这条状态机为什么识别方向？

先在前驱位置收到 P，电位变为 +1；随后中心收到 C，高段的 +1 立即令 V=2，发出脉冲。若 C 先来，V 从 0 经 +1、−1 又回 0，不会发放。

干扰 N 会使 +1 → 0 或 0 → −1，因此打断或压低已积累的候选状态。重复 P 会重新置为 +1。

计算边界

这是单个输出神经元、一个事件逐次到达的状态机。多个真实 DVS 事件可能交错；物理层 2 是普通层，参考笔记记录其输入 feature 按高索引先计入。这里的低位钳制遵循同一笔记中的实验结论，阈值、初始值和复位直接对应本脚本配置。它不模拟拥塞丢事件或与其他层的传播延迟。
